separate real-text project. A validated simulator method does not establish
human intent, human values or historical process correspondence.

## Research question

What information about a maker survives in an artifact, what additional evidence
resolves ambiguity, and which representations let a reader use that information?
Known-answer construction lets the project distinguish information limits,
decoder failures, supplied constraints and validated improvements in a method.

## What is implemented

The code contains the closed V1–V18 studies and the V19 apparatus. V19 has
an exact local-goal dependency-edit world, learned and exact readouts, retention,
transfer and evidence-policy comparisons, source-frozen native execution,

scientific result: consult [current status](results/v19/CURRENT_STATUS.json),
[coverage](results/v19/TEST_COVERAGE.json) and each named result's review.

V21 adds law-marginal ceilings, converged/fresh-law direct rivals, shared-maker

tool action is not an AI-use generator and must not be relabelled as one.

## Scope and limits

Report constructed-method results separately from claims about mechanisms in
people. A supplied-law oracle is a ceiling, probe accuracy is not selective causal
access, execution is not numerical acceptance, and accepted exploration is not
confirmation. Preserve failed instruments, negative results, unknowns and costs.
The [hypothesis store](docs/theory/READING_INTENT.md) records those qualifications.

## Install and run

Use the repository's declared interpreter and the campaign-specific procedure in
[AGENTS.md](AGENTS.md). Inspect native ownership before any execution. Do not
synchronize an environment used by a live worker, restart a closed version, or
copy a historical launch command into a current campaign. Scoped checks and
reproduction belong in an isolated checkout with the relevant source and inputs.

## Human and AI contribution boundary

The project retains curator statements, analyst interpretations and measured
results as distinct sources. See the [theory source legend](docs/theory/README.md),
[citation metadata](CITATION.cff) and [license](LICENSE). Simulator labels do not
convert unobserved human reasoning into a recorded fact.
