# Ghost Scale Simulation — Implementation Specification

**Author of spec:** Abraham Haskins, PhD
**Target:** an autonomous coding agent, building in one pass
**Status:** paper-seed. Build it as if a referee will read the repo, because one will.

---

## 0. Read this first

You are building a computational model, not a demo. The difference is that a demo produces
the expected figure and a model can fail. Every headline result in this spec has a matching
null condition that **must** be implemented and **must** produce a null. If a null condition
produces the effect anyway, that is a finding and you report it in `RESULTS.md` rather than
tuning it away.

The single largest failure mode for this build is **encoding the conclusion into the
likelihood matrices and then reporting it as a result.** Section 9 exists to prevent that.
Read Section 9 before writing any model code.

### What is being modeled, in one paragraph

A human observer looking at an artifact runs an inference over the hidden goals of whoever
made it. That inference is expensive, so the observer only sustains it when it expects to
learn something. Artifacts made by humans carry recoverable goal information. Artifacts
generated by diffusion or autoregressive models are structurally rich but carry no
recoverable goal information, because no goal caused their structure. When the observer
detects this, it disengages to conserve metabolic budget. This is the **generative crash**.
The **Ghost Scale** is a provenance signal that lets the observer make that determination
cheaply and early, before it has burned the budget. When the provenance signal is absent or
dishonest and the observer trusts it anyway, the observer does not disengage; it instead
converges on a confident but arbitrary goal attribution. That is the **trust exploit**, and
it is the mechanism of biological model collapse.

## 3. The generative model

All agents are discrete POMDPs. Below, "the observer" is the agent whose beliefs we measure.

### 3.1 Hidden state factors (observer's model)

| idx | factor | cardinality | controllable | meaning |
|---|---|---|---|---|
| 0 | `provenance` | 4 | no | `CREATOR`, `POLISHED`, `CURATOR`, `GHOST` — true origin of the artifact |
| 1 | `creator_goal` | 4 | no | `G0..G3` — the hidden preference the maker was optimizing. This is the R being extracted. It is the alignment payload. |
| 2 | `attention` | 2 | **yes** | `DEEP`, `SKIM` — depth of the observer's simulation of the maker |

`num_states = [4, 4, 2]`

Factor 2 is the only controllable factor. `num_controls = [1, 1, 2]`.

### 3.2 Observation modalities

| idx | modality | cardinality | depends on | meaning |
|---|---|---|---|---|
| 0 | `artifact_features` | 8 | `provenance` × `creator_goal` × `attention` | the observable content of the artifact, τ |
| 1 | `ghost_signal` | 5 | `provenance` only | declared tier: `SIG_CREATOR`, `SIG_POLISHED`, `SIG_CURATOR`, `SIG_GHOST`, `UNSIGNED` |
| 2 | `effort` | 2 | `attention` only | `LOW_COST`, `HIGH_COST` |

`num_obs = [8, 5, 2]`

### 3.3 A — likelihood matrices

Shapes, in pymdp object-array convention:

```
A[0].shape == (8, 4, 4, 2)    # features | provenance, goal, attention
A[1].shape == (5, 4, 4, 2)    # signal   | provenance (constant across goal, attention)
A[2].shape == (2, 4, 4, 2)    # effort   | attention  (constant across provenance, goal)
```

#### A[0] — `artifact_features`. This is the load-bearing matrix. Build it as follows.

Define a **goal-signature** function. For each goal `g`, a base distribution `sig[g]` over the
8 features: a peaked categorical with mass concentrated on a goal-specific pair of features,
normalized. Construct `sig` once, deterministically, and assert that the four signatures are
pairwise distinguishable (pairwise Jensen-Shannon divergence above a threshold recorded in
config).

Define a **structure-only** distribution `noise_free_synth`: a peaked categorical over the 8
features that is **not uniform** and is **identical for all goals**. Draw it once from a
Dirichlet with concentration < 1 so it is visibly structured, then freeze it.

> **This is the most important modeling decision in the build.** Synthetic artifacts are
> *not* noise. They are highly structured. What they lack is any dependence of that
> structure on a goal. Entropy over features stays low; mutual information between features
> and `creator_goal` goes to zero. If you make the synthetic column uniform over features
> you have modeled static, not generative AI, and the entire result becomes an artifact of
> surprise rather than unidentifiability. A referee will find this in ten minutes.

Now mix, per tier, with an **intent-transmission coefficient** `alpha[p]`:

```
alpha = {CREATOR: 1.00, POLISHED: 0.95, CURATOR: 0.60, GHOST: 0.05}

A[0][:, p, g, DEEP] = alpha[p] * sig[g] + (1 - alpha[p]) * noise_free_synth
```

`alpha` values are the Ghost Scale opacity levels read as fraction of recoverable intent.
That correspondence is the framework's central empirical commitment and should be stated as
such in the README, not smuggled in as an implementation detail.

For `SKIM`, intent is not recoverable at any tier:

```
A[0][:, p, g, SKIM] = noise_free_synth    for all p, g
```

This is what makes `DEEP` epistemically valuable and `SKIM` cheap. Do not add extra noise to
`SKIM`; the point is that skimming does not resolve goals, not that skimming is unreliable
about content.

#### A[1] — `ghost_signal`. This is where κ lives.

Two distinct objects, and the code must keep them separate:

- **`A1_generative`** — the true signal-emission process used by the environment.
- **`A1_observer`** — the observer's *belief* about that process. Its precision is κ.

Environment side, parameterized by `honesty` and `signing_rate`:

```
with prob (1 - signing_rate):  emit UNSIGNED
otherwise:
  with prob honesty:           emit the signal matching true provenance
  with prob (1 - honesty):     emit SIG_CREATOR   # the bad actor's move
```

Observer side, parameterized by κ ∈ [0, 1]:

```
A1_observer[:, p, :, :] = kappa * truthful_row(p) + (1 - kappa) * uniform_over_5
```

κ = 1 means the observer treats the declared tier as ground truth. κ = 0 means the observer
ignores the channel entirely and must infer provenance from content. **κ is the precision of
one likelihood mapping, not a global temperature.** See Section 8; there is an entire
experiment devoted to proving these are different.

#### A[2] — `effort`. Deterministic.

```
A[2][LOW_COST,  :, :, SKIM] = 1.0
A[2][HIGH_COST, :, :, DEEP] = 1.0
```

### 3.4 B — transitions

- `B[0]` (`provenance`): identity. Provenance does not change within an episode.
- `B[1]` (`creator_goal`): identity within an episode.
- `B[2]` (`attention`): fully controllable. `B[2][:, :, a]` sets the next attention state to
  `a` deterministically, for both actions.

### 3.5 C — preferences

```
C[0] = zeros(8)     # NO preference over artifact features
C[1] = zeros(5)     # NO preference over signals
C[2] = [+c_effort, -c_effort]   # prefers LOW_COST over HIGH_COST
```

`c_effort` is a config scalar, default `0.5`, swept in Experiment 3.

> **Read this twice.** The observer has **no preference over provenance** and **no
> preference over any signal value**. It does not dislike AI. It has never heard of AI. It
> only dislikes spending energy. Every disengagement from synthetic content must therefore
> arise from the epistemic term of expected free energy going to zero, leaving the effort
> cost unopposed. If you ever find yourself adding a negative preference on `SIG_GHOST` or
> on the `GHOST` provenance state, stop: you have written the conclusion into the premises
> and the result is worthless.

### 3.6 D — priors

`D[0]` (provenance) and `D[1]` (goal) are the observer's priors. **Observers must be
heterogeneous.** For each observer `i`, draw

```
D[1] = normalize(uniform_prior + eps * rng.dirichlet(ones(4)))
```

with `eps` a config scalar (default `0.35`). Draw `D[0]` from a mildly perturbed prior the
same way.

Heterogeneity is not cosmetic. The H2 result is a claim about **between-observer**
disagreement. If all observers start identical and share a seed, between-observer variance
is zero by construction for every condition and the experiment measures nothing. Conversely,
if heterogeneity alone drives disagreement, the effect must appear in the human condition
too — which is exactly what null test N3 checks.

### 3.7 Agent construction

```python
agent = Agent(
    A=A, B=B, C=C, D=D,
    control_fac_idx=[2],
    policy_len=2,
    inference_horizon=1,
    use_utility=True,
    use_states_info_gain=True,
    action_selection="deterministic",
)
```

`policy_len=2` so the agent can evaluate "engage once more, then decide." `policy_len=1`
collapses the interesting dynamics; do not use it for headline runs. Include a `policy_len`
sweep as a robustness check.

## 4. Creators and the environment

### 4.1 Human creators

A human creator is a **real pymdp agent**, not a sampler. It has its own small POMDP with a
hidden preferred outcome (its `C`, drawn per creator) and it selects actions to realize that
preference. Its action sequence is rendered into an `artifact_features` observation via the
same `sig[g]` machinery.

This matters. The theoretical claim is that human artifacts carry recoverable goals *because
a policy optimizing a reward function actually produced them*. If human artifacts were
generated by sampling from `sig[g]` directly, the simulation would assume its own conclusion.
Generate them from a policy and verify post hoc that the resulting empirical feature
distribution approximates `sig[g]`; record the approximation error in `RESULTS.md`.

### 4.2 Synthetic generators

A synthetic generator has **no C and no policy**. It samples features from
`noise_free_synth` directly. This asymmetry between creator classes is the entire theoretical
content of the model and should be commented as such in `creators.py`.

### 4.3 Hybrid tiers

`POLISHED` and `CURATOR` are produced by mixing: a human creator generates the artifact, then
a fraction `(1 - alpha[p])` of its features are resampled from `noise_free_synth`. Verify
empirically that the resulting feature distribution matches the `A[0]` column for that tier
within tolerance. **If it does not match, fix the generator, not the A matrix.** The A matrix
is the observer's model of the world; the generator is the world. They are allowed to differ,
but only deliberately, and every deliberate mismatch gets a named config flag.

## 5. Experiments

Each experiment is a module under `ghostscale/experiments/`, runnable standalone, writing a
tidy CSV to `results/` and a figure to `figures/`. Defaults: **200 observers**, **40
timesteps**, **20 seeds**, unless stated.

### E1 — The generative crash (maps to H1)

**Design.** 1×4 across true provenance. Signals honest, `signing_rate=1.0`, κ=0.9.

**Measure.** Per observer: timestep of first `SKIM` action; cumulative `DEEP` steps;
epistemic component of EFE for the `DEEP` policy at each t; posterior entropy over
`creator_goal` over time.

**Prediction.** Disengagement latency is short and tightly clustered for `GHOST`, long or
absent for `CREATOR`, monotonic across tiers. The epistemic value of `DEEP` collapses toward
zero for `GHOST`, and the switch is a step function in the EFE landscape rather than a
gradual drift — decompose EFE into pragmatic and epistemic terms and plot both, because the
step-vs-gradual distinction is the whole claim and it lives in that decomposition.

**Figure.** Two panels: disengagement survival curves by tier; EFE decomposition over time.

### E2 — IRL convergence failure (maps to H2, headline result)

**Design.** 2×2 factorial: true origin {`CREATOR`, `GHOST`} × declared signal
{`SIG_CREATOR`, `SIG_GHOST`}. Observers forced to `DEEP` for the first `k` steps (config,
default 10) so that every cell gets a comparable inference attempt, then free.

**Measure.**
- *Between-observer disagreement*: entropy of the distribution of modal inferred
  `creator_goal` across the 200 observers. This is inter-rater reliability.
- *Within-observer confidence*: mean posterior entropy over `creator_goal` per observer.
- The **dissociation** between the two is the signature of hallucination.

**Prediction.** The cell `(true=GHOST, signal=SIG_CREATOR)` shows **low within-observer
entropy and high between-observer disagreement**: every observer is confident, and they all
disagree. That is `R_hallucinated`. The cell `(true=GHOST, signal=SIG_GHOST)` shows early
disengagement and high within-observer entropy — uncertainty correctly represented rather
than resolved into a fabrication.

**Figure.** 2×2 panel of confidence-versus-disagreement scatter, one point per observer.

This is the figure that goes in the email. Make it good.

### E3 — Ghost Scale titration (maps to H3)

**Design.** Full four-tier ladder × observer type {`calibrated κ=0.9`, `naive κ=0.1`} ×
`c_effort` sweep.

**Measure.** Cumulative `HIGH_COST` observations (metabolic expenditure); accuracy of final
goal posterior against ground truth on `CREATOR` trials.

**Prediction.** Calibrated observers spend measurably less total effort across a mixed corpus
**without** losing goal-recovery accuracy on genuine human artifacts. The Ghost Scale buys
metabolic savings at no epistemic cost. If calibrated observers *do* lose accuracy on human
artifacts, that is a real cost of the framework and it must be reported, not suppressed.

### E4 — The trust exploit (maps to H6)

**Design.** κ sweep from 0 to 0.99, `honesty` sweep from 1.0 down to 0.5, on `GHOST` content.

**Measure.** Rate of confident-but-arbitrary goal attribution; KL between the observer's
final goal posterior and its own prior (the "Bayesian surprise that shouldn't exist").

**Prediction.** A two-dimensional region where high κ and low honesty jointly produce
sustained engagement with structureless content. Locate the boundary. Report whether it is
sharp or graded.

### E5 — κ is not γ (the precision baseline)

See Section 8. This is a load-bearing methodological experiment, not an optional extra.

### E6 — Corpus corruption and the alignment payload

**Design.** A population of 50 creators with a known distribution over goals — call it
`C_true`, the population's aggregate preference. A downstream "aggregator" observer watches
`N=2000` artifacts drawn from a corpus with a contamination fraction `f` of unsigned
synthetic artifacts, and accumulates a posterior over the population goal distribution,
`C_recovered`.

**Measure.** `KL(C_recovered || C_true)` as a function of `f`, at κ ∈ {0.1, 0.5, 0.9}, and
under `signing_rate` ∈ {0.0, 0.5, 1.0}.

**Prediction.** Recovery degrades with contamination, and the degradation is **strongly
attenuated by an honest signal at any κ**, and **worsened by high κ under low signing rate**
(the trusting observer with no signal is the most corruptible).

This is the experiment that makes the whole thing an alignment result rather than a
perception result. It is the CIRL loop in miniature: `C_recovered` is what you would hand a
downstream agent as its preference prior. Give it real attention.

## 6. Metrics module

`ghostscale/metrics.py` implements, with docstrings stating the formal definition:

- `epistemic_value(agent, policy)` — expected information gain about factor 1
- `pragmatic_value(agent, policy)`
- `between_observer_entropy(posteriors)` — entropy of modal-goal distribution across observers
- `within_observer_entropy(posterior)` — mean Shannon entropy of goal posterior
- `mutual_information_features_goal(A0, p, attention)` — MI between modality 0 and factor 1,
  conditioned on provenance. **This is the diagnostic that distinguishes unidentifiability
  from noise.** Report `H(features | p)` alongside it. The synthetic condition must show low
  MI *and* low entropy. If it shows low MI and high entropy you have built the noise
  strawman.
- `psi_analogue(posterior, prior, kappa, engaged)` — the discrete stand-in for Ψ. Defined as
  `[engaged] * (-ln(1 - kappa)) * KL(Q(goal|tau) || P0(goal))`. Report it, and state clearly
  in the README that the sigmoid gate has been replaced by the binary engagement decision and
  that this is a reimplementation of the intuition, **not a port of the closed-form
  equation.** Do not claim equivalence.

## 8. E5 in full — proving κ is not γ

**The objection this pre-empts.** Active inference already has a precision parameter, γ,
which scales the softmax over policies and controls how decisively an agent commits to its
best policy. A reviewer will ask whether κ is just γ with new vocabulary. If it is, the
framework contributes nothing beyond existing machinery, and the correct response is to say
so and move on. So test it.

**The claim.** γ is a **global** scalar on policy selection. κ is the **precision of a single
likelihood mapping** — the provenance channel, `A[1]`. They act at different points in the
inference and produce different behavioral signatures. Specifically, κ produces
**content-selective** engagement: sustained engagement with human artifacts and rapid
disengagement from synthetic ones, within the same observer, under the same γ. γ can only
produce **indiscriminate** shifts in decisiveness.

**Design.** Three arms, same corpus (mixed provenance), same observer otherwise:

| arm | κ | γ | prediction |
|---|---|---|---|
| A | swept 0 → 0.99 | fixed at default | engagement **selectivity** (Δ between human and synthetic) rises with κ |
| B | fixed at 0 | swept low → high | overall engagement rate shifts; **selectivity stays near zero** |
| C | fixed at 0.9 | swept low → high | selectivity is preserved across the γ range |

**Primary metric.** `selectivity = P(DEEP | true=CREATOR) - P(DEEP | true=GHOST)`, plus the
overall engagement rate as a control.

**Falsification.** If arm B produces selectivity comparable to arm A, κ is redundant with γ.
Report that plainly in `RESULTS.md` and in the README abstract. This is a real possible
outcome and the build is more valuable for being able to detect it.

**Subtlety to handle carefully.** In arm B, with κ=0, the observer can still infer provenance
from **content**, because `A[0]` differs across provenance columns. So some selectivity may
appear even without the signal channel. That is not a failure; it is the model correctly
capturing that a skilled observer can sometimes spot synthetic content unaided. Report
content-only selectivity as a named baseline, and define the Ghost Scale's contribution as
**the increment above it, and the reduction in how many `DEEP` steps are needed to get
there.** The Ghost Scale's claim was never that people cannot detect AI. It was that
detecting it costs them something the signal could have given away for free. Make sure the
metrics can express that: report both selectivity *and* steps-to-disengage.

## 9. Null conditions — mandatory, in `tests/test_nulls.py`

Each is a pytest that runs a reduced version of the relevant experiment and asserts the
effect is **absent**. A null that fails to be null is a finding; record it and do not tune
around it.

**N1 — Intent restoration.** Set `alpha[GHOST] = 1.0` so synthetic artifacts carry full goal
signature. The crash must vanish; disengagement latency for `GHOST` must become
indistinguishable from `CREATOR`. *Proves the effect is driven by intent-recoverability, not
by the label.*

**N2 — Free cognition.** Set `c_effort = 0`. Disengagement must vanish across all tiers.
*Proves the crash is a metabolic trade-off, not a distaste.*

**N3 — Homogeneous observers.** Set `eps = 0` and share one RNG seed. Between-observer
disagreement must fall to approximately zero in **every** cell of E2, including
`(GHOST, SIG_CREATOR)`. *Proves the H2 result requires genuine observer heterogeneity and is
not a sampling artifact.*

**N4 — Label shuffle.** Randomly permute the mapping from true provenance to `alpha` while
leaving everything else intact. All effects must vanish. *Standard permutation control.*

**N5 — Signal blackout.** Set `signing_rate = 0`. The difference between calibrated and naive
observers must collapse. *Proves the Ghost Scale effect requires the Ghost Scale.*

**N6 — The noise strawman, run deliberately.** Replace `noise_free_synth` with a uniform
distribution over features. The crash should still occur, **but for a different reason**, and
`mutual_information_features_goal` together with `H(features)` must separate the two cases:
structured-unidentifiable shows low MI with low entropy; uniform-noise shows low MI with high
entropy. Assert the diagnostic distinguishes them. *This is the referee-proofing test. It is
the one most likely to be skipped and the one most worth having.*

**N7 — Preference leakage audit.** An assertion, run at model-construction time in every
experiment, that `C[0]` and `C[1]` are exactly zero vectors. *Guards against the single most
likely way this build silently becomes worthless.*

## 10. Invariant tests, in `tests/test_model_invariants.py`

- Every `A[m]` column sums to 1 along axis 0; every `B[f]` column sums to 1.
- Shapes match Section 3.3 exactly.
- Pairwise JS divergence between `sig[g]` exceeds the configured threshold.
- `H(noise_free_synth)` is **below** the configured "structured" ceiling. Assert explicitly
  that synthetic content is not high-entropy.
- `mutual_information_features_goal` is monotonically decreasing in tier order
  `CREATOR > POLISHED > CURATOR > GHOST`.
- Empirical feature distributions from `creators.py` match the corresponding `A[0]` columns
  within tolerance; any deliberate mismatch is behind a named flag.
- Reproducibility: identical seed produces identical CSV.

## 11. README — mandatory crosswalk section

The README must contain a section titled **"Relationship to existing active inference work
on Theory of Mind."** It maps this model's constructs onto the published literature, in a
table, with citations. At minimum:

| this model | corresponding construct | source |
|---|---|---|
| `creator_goal` as a hidden state factor inferred by the observer | opponent preference parameters θ_j inferred online | Albarracin et al. 2026, arXiv 2602.20936 |
| observer's model of the creator | structurally matched other-model M_other | Albarracin et al. 2026 |
| κ as precision on the provenance channel | reliability-gating r between learned and static ToM prediction | Albarracin et al. 2026, Eq. 15 |
| engagement policy over `attention` | epistemic value term in social EFE | Pitliya et al. 2025, arXiv 2508.00401 |
| Ghost Scale tiers | *no existing analogue* | — |
| structureless generator with no C | *no existing analogue* | — |

The section then states, in plain prose, the two things this model adds:

1. **What sets the weight.** Albarracin et al. fix the empathy parameter λ exogenously and
   name "what sets λ" as their central open question, observing that accurate other-modeling
   with low λ produces *better exploitation* rather than cooperation, and that precision
   optimization alone is motivationally neutral. κ, gated on artifact provenance and on
   value-divergence, is a candidate answer: the weight on another agent's inferred
   preferences should scale with the evidence that those preferences exist and with their
   alignment to one's own.
2. **What happens when the other has no preferences at all.** Existing ToM-in-active-
   inference work assumes the observed other *is* an agent with a C. This model asks what
   happens when it is not, and finds that the inference does not fail gracefully: under high
   trust it fabricates.

Write this section honestly. Do not overstate novelty. The value of the contribution is that
it slots into a named gap, and that argument is weakened, not strengthened, by claiming more
ground than it holds.

## 14. Things you may not change

The zero preference over provenance and signal. The structured-not-uniform synthetic
likelihood. The observer heterogeneity requirement. The null test suite. The honest README
crosswalk. These are the load-bearing constraints; changing any of them converts a result
into a demonstration.
