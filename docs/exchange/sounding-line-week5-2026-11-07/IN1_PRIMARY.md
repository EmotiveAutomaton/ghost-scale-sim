# IN1: Does a writer report stronger emotion when the event better matches its proposed trigger profile?

**Hypothesis.** Does a writer report stronger emotion when the event better matches its proposed trigger profile?

**METHOD.** Fit within-prompt standardized intensity on the signed non-valence trigger index, with prompt intercepts and the frozen valence, confidence and response-style controls. Refit the full model in 2,000 whole-writer bootstrap draws, including all four channel companions.

**Found.** Across the four prompted emotions, the frozen trigger-fit index adds a positive descriptive association with reported intensity beyond valence, confidence and response style; only RAGE and DISGUST clear their separate bars.

The table gives standardized fitted slopes and whole-writer 95% bootstrap intervals; channel labels follow the frozen prompt mapping.

| Contrast | Estimate | 95% interval | Registered reading |
|---|---:|---|---|
| Pooled trigger-fit slope | 0.171252 | [0.132517, 0.208841] | supports; bar 0.1 |
| FEAR | 0.028376 | [-0.051972, 0.100564] | inconclusive |
| RAGE | 0.273093 | [0.192601, 0.351435] | supports |
| PANIC/GRIEF | 0.176189 | [0.092355, 0.256327] | inconclusive |

Support: 2,190 reports from 1,322 writer clusters. Numerical controls pass signed and exact-null native handlers with the same full draw count; complete data and output replay passes. No p-values are introduced.

**Means and scope.** These are observational, prompted-event self-reports from Crowd-enVENT, not biological channel measurements or causal interventions. The frozen non-valence appraisal mapping remains an analyst operationalization. Cite Troiano, Oberländer and Klinger (2023), doi:10.1162/coli_a_00461; corpus CC BY 4.0.
