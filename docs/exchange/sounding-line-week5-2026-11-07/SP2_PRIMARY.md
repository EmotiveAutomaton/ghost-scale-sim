# Does steady climate control sharpen thermal sensitivity?

**Hypothesis.** Does steady climate control sharpen thermal sensitivity?

**METHOD.** Fit sensation against operative temperature within each building, then compare median slopes between air-conditioned and naturally ventilated buildings. Retain the acceptable-temperature width as a separate descriptive companion and refit 2,000 building-cluster bootstrap draws.

**Found.** Air-conditioned buildings have a larger median sensation-per-degree slope than naturally ventilated buildings in this observational sample; cooling type does not separate thermal history from perceived control.
