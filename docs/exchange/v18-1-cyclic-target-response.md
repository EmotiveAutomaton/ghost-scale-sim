# V18.1 fresh two-target query response

Can a cheap query rule tied only to changed public target parts repair a harder two-dependency task? Yes descriptively in this constructed screen. Across 192 fresh seven-part contexts with four nested histories, two target-aware parent queries isolate the true law and give both dependency learning and the equally informed direct compiler 100% task success. One target-aware query always leaves two laws and both methods at 0%; the historical two-query fixed sequence is a designed placebo that leaves all four laws and 0%; the decision selector succeeds in 33.33% because it exhausts the 32,768-operation envelope in fork and grouped contexts. Target-aware acquisition costs 43 operations, but primitive robust search still succeeds in only 52.60%, separating evidence sufficiency from planning work. This is descriptive constructed-mechanism evidence, miniature—architecture untested; it is not a third primary, does not establish dependency-representation necessity, and does not establish transfer to action/routine evidence or human learning.

The screen fixes two independent reciprocal target-relevant cycles in each public
four-law candidate family before outcomes. The query rule sees only the changed public
target parts and the public candidates. The historical fixed sequence queries two late
labels whose outcomes are invariant across the four laws, making it a designed placebo
rather than a weak fitted rival. All action methods receive identical selected evidence.

Frozen-source reconstruction passed all 18,432 rows across 768 cases. It independently
checked candidate filtering, physical execution, forecast truths, observation outcomes,
evidence identity and work receipts. A fresh extraction of the archived source regenerated
72 outcome-independently selected rows. The first admission attempt is retained: its only
failure was a skipped existing Stitch check because the pinned binary path was absent from
that test environment. The unchanged rerun with the existing pinned binary passed all 52
checks without skips. No dependency or environment changed.

This resolves the cheap context-query selection question but exposes a planning boundary:
sufficient evidence does not make primitive candidate-set action reliable at the declared
work cap. The next commissioned descriptive contrast asks whether target-relevant executed-
action evidence can supply the same two-dependency repair under a two-observation cap without
using a direct parent cue. Both permitted final contrasts are already frozen and held; this
continuation remains active and the next contrast cannot become a third primary.
