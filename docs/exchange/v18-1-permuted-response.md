# V18.1 opaque-label discovery response

Does useful support evidence survive when part labels stop revealing dependency order? Yes, descriptively, but the effect weakens and it still does not make learned structure necessary for acting. In seven-part tasks at 32,768 operations, two fixed support observations raise task success from 78.49% to 92.69%—a 14.19-point gain—and reduce mean squared held-out legality probability error from 0.04678 to 0.00580. With numbered parts the same comparison was 78.78% to 95.07%. The equally informed direct compiler still solves 100%; deriving a safe order from the public candidate-law union costs 177.97 operations instead of 155, a 14.8% increase. This is a descriptive constructed-mechanism result over deterministic relabelings of retained structures, miniature—architecture untested. It does not establish human learning or a need for dependency inference.

The intervention deterministically relabels 2,304 retained five- and seven-part
contexts with four histories nested in each. Every method receives the same public
candidate laws and relabeled evidence; none receives the label map or a marker for
the true law. The direct rival derives a topological order that is safe for the
entire public candidate-law union and pays for its derivation, checking and execution.
Five-part task success was already nearly saturated: fixed observations raise it
only from 97.83% to 98.20% under opaque labels.

All 175,104 retained rows reconstruct from immutable block outputs. Every submitted
program was independently executed against the true physics and every forecast,
observation and charged cost was reconstructed. A fresh extracted-source replay
regenerated 684 outcome-independently selected rows. The batch contains 2,226
concrete law configurations and 20 unlabeled topologies; relabeling does not create
new architecture or untouched structural support.

One final primary was frozen only after discovery: two fixed support observations
versus no added observation on 1,152 fresh seven-part contexts, with a five-point
practical margin. Its one-sided 0.025 empirical Bernstein bound reserves familywise
0.05 for at most two primaries. Forecast error and direct compilation are secondary
boundaries; they cannot replace the primary, and no result-dependent extension is
allowed. The active run has no filed result yet, so this is not confirmation or
campaign closure.

The freeze apparatus initially hardcoded discovery sampling language and could not
record an untouched-sampling declaration. That record-layer failure was repaired
before freezing: the runtime now copies the plan's declared sampling contract, a
regression test requires it, and the isolated 49-check suite passes without skips.
The first final block independently passes physics, evidence, cost, private-field
separation and direct-route checks. The repair changes no completed discovery output.

What this validation could not check: deterministic label permutation is not a new
structural family; the discovery branch was selected after earlier outcomes; the
final contrast is still running; and no constructed result establishes human
attention, beliefs, values or acquisition of another person's aims.
