## 3. Questions that can change Sounding Line

The main question is:
**Can a coherent model of contribution and process recover useful distinctions that direct reading misses, at matched evidence and measured cost?**

Ask four subsidiary questions:
1. When do separate goal/process estimates combine into an impossible account?
2. Which historical distinctions survive a persistent maker representation, and which require an episode ledger?
3. Which additional observation actually improves a contribution judgment, particularly when sources repeat or disagree?
4. When the true process is missing from the candidate set, can the system notice and repair the omission?

These are mechanism and measurement questions in constructed worlds.
Human correspondence must be established in Sounding Line.
Synthetic success cannot certify probabilities about an actual author's private intention.
Synthetic failure can still identify a defect that is actionable in a human reader.

## 7. Evidence conditions and outcome definitions

Freeze four primary evidence tiers:
- **Artifact:** final artifact and passage boundaries only.
- **Workflow context:** artifact plus permitted initial/task/tool-availability facts.
- **Sparse record:** context plus a fixed partial event witness.
- **Complete record:** all observed production events, while unobserved aims remain latent.

Additional stress conditions are separately labelled:
wrong context, copied context, irrelevant context, corrected context, missing candidate and shifted workflow.
A record-backed case and an artifact-only case are different inference tasks.
Do not pool them into one headline accuracy.

Primary outcomes:
- AI/tool involvement classification under the declared source semantics;
- recorded handling classification;
- event and operation-order recovery;
- calibrated local-goal prediction in the constructed world;
- joint compatibility and unsupported-attribution rate.

Use proper probability scores, especially log loss and Brier score.
Also report discrimination, calibration, coverage and cost separately.
Retain invalid outputs as failures under the frozen scoring rule.
Report unknown/unrepresented mass rather than renormalizing it away.
A wide accurate distribution can be more useful than a sharp inaccurate one.
A particular correct new observation can increase posterior entropy; average information value is a different quantity.
Narrower intervals do not by themselves establish better accuracy.

For mutually exclusive candidate histories, weights sum to one including unknown mass.
For simultaneous local aims, use a joint multi-label model or explicitly conditional marginals.
Do not force every word in a goal cloud to compete as a mutually exclusive alternative.
Panel marginals must point back to compatible joint hypotheses.
A viewer must not combine the most likely goal and the most likely process when their conjunction has negligible support.

## 8. Comparators and fairness

Every primary comparison includes:
- training prior or frequency baseline;
- direct evidence reader at the same information level;
- legal-support/template baseline;
- structured joint contribution account;
- exact supplied-law oracle as a labelled ceiling.

Use existing tiny recurrent/transformer machinery only when it serves the comparison.
A new model does not win by receiving oracle factors or more labels.
Match training cases, evidence, output ontology and scored population.
Match or explicitly charge computation used for candidate proposal, execution, reranking and decoding.
Report parameter count, training cost and inference cost; equal final smoothing is not equal capacity.

Separate two questions:
1. Does a representation preserve information?
2. Can the trained decoder use it under the available labels and compute?

Include an exact-state or full-evidence reference to expose missing information.
Include a low-capacity decoder and an appropriately capable direct rival to expose decoder failure.
A decoder that contradicts a supplied event fails its evidence-use control.
Apply mechanical support restrictions equally across arms.
Do not make a naive unrestricted baseline absorb losses from already observed facts.

Freeze the first practical margin before new results.
Default diagnostic margin is 0.02 nats per scored decision, inherited only as a planning convention.
Also require a meaningful reduction in unsupported attribution or a useful cost/label improvement.
Report effect size and uncertainty even when a threshold is not crossed.
The frozen main outcome takes priority over favorable subgroups.

If structure helps only when legal rules are supplied, report a constraint-use gain.
If an internal intervention changes every prediction, report nonspecific disruption.
If joint predictions improve coherence without improving truth, report that limited benefit.
If context sharpens the wrong account, report increased confidence as harm rather than progress.
If a simple baseline wins, return it to Sounding Line and retain the failed mechanism's scope.

The campaign succeeds scientifically when it resolves a consequential design uncertainty with an adequate instrument.
It succeeds operationally when the admitted five-day service, resource and closeout contract is met.
Those are separate judgments.
A shorter complete study does not silently satisfy the five-day service requirement.
A continuously occupied machine does not establish a useful discovery.
The strongest acceptable return is a measured improvement in Sounding Line's real contribution reader, with Ghost explaining why it works and where it fails.

## 15. Root integration notes and shared ABI

Sounding Line owns the canonical exchange schema. The existing operations vocabulary includes `propose`, `select`, `reject`, `revise`, `integrate`, `repair`, `retain` and `realize_surface`; do not silently map an inferred mental state to an observed event.

Add source/region anchors, evidence roles, trace support, downstream scope and epistemic status in a versioned compatible outer object or payload with a documented mapping. Candidate histories belong in a separate inferred object, never an observed `ProcessCase` merely because they parse. `ContributionNetwork.author_share` intentionally rejects exchangeable-event author-share calculation; keep that guard. Root personally inspected these source definitions at Sounding Line commit `3c64aea945d857a52d4b679a3e3a0465aa99fe92`.

Use one shared model-setting registry and resource owner. All interfaces need a clear unknown interpretation. In an enumerable world, outside-candidate probability can be computed against the full declared universe.
