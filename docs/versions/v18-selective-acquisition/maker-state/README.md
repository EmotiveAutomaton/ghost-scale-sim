# V18.2: persistent maker state

The curator commissioned this [unchanged specification](CODING_PACKAGE.md) on
19 September 2026. This is discovery, separate from V18.1's frozen primaries.
The absolute report start is 20 September 13:00 UTC; delivery is 15:00 UTC
(08:00 PDT). The cumulative ceiling is 18 worker CPU hours, including training
and verification. A finite, useful queue may finish earlier.

The finite queue is complete. The [final report](FINAL_REPORT.md) records all
branches, follow-ons, repairs, limitations and six reconstructed examples. The
[specification index](../SPECIFICATIONS.md) binds all three V18 intake sheets.

The implementation wraps V16's four-cell executable board and its real repeated
fragment learner. Thirty-six candidate states cross acquired repertoire,
three stable tradeoffs, default local goal and prior belief. A received signal
updates belief; the reader's own fact does not. A softmax policy combines goal
error, tradeoff and description cost. Acquired two-action fragments can make
three-action programs affordable under the same two-token budget. Primitive
execution cost is retained separately. None of these coefficients are human values.

Readers receive a validated JSON packet, never the separate truth record or a
future response. Artifact, artifact-history and process-history are separate
evidence tiers. Each arm within a tier receives the same packet. Exact finite
inference preserves a distribution over candidates. The raw-history rival uses
a fixed context-distance kernel; the direct rival integrates the same declared
policy family without conditioning on history. The oracle is evaluator-only.

Training, development and test use disjoint maker identities and disjoint
task/feature incidence structures on the existing board. These are held-out
task structures, **not independent physical architectures**. Later restricted
operation support is a further world condition. All comparisons remain
miniatures with architecture untested.

The split network has a long-history encoder and a current-context encoder;
the flat network receives exactly the same features. Both learn by backpropagation
from sampled future artifacts, with matched example order, updates and validation
selection. Neither receives latent skill/preference labels. Architectural block
swaps do not identify uniquely psychological coordinates. Training initially uses
1,250 makers, 10,000 history episodes and 11,250 supervised tier/probe examples;
64 different development makers choose the epoch. The crossed goal/signal cell
is absent from training. Test labels never select representations.

G0, G1/G2/G3/G5/G6 and the learned/G4 comparison completed their source-frozen
core queue. Completed follow-ons cover longer histories/novel goals, uncertain
access, charged observation execution, dependent uptake, restricted operations
and a second training seed after the conceptual contrasts. A separately fitted
assembly maker and a physical selective-uptake dependency comparison also ran.
Each ordinary block
starts at 128 independent histories. No positive result is required to proceed.

The [results](RESULTS.md), [public proof records](../../../../results/v18/maker-state/README.md)
and [blind synthetic bridge](../../../../results/v18/maker-state/bridge-1/README.md)
distinguish executed, verified, planned and limited scope. Failed or partial cells
must retain explicit dispositions. No conclusion transfers automatically to people,
consciousness, real-text readers or an alignment guarantee.
