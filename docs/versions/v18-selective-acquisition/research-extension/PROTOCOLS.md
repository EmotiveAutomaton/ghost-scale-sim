## E: learned memory and predictive summaries

The generator supplies the same public histories, public world description and
question to every learned reader. Histories have 8, 16 or 32 observations. Training
uses 128 histories per architecture cell, development 16, and test 32, across the
16 cells. Train/development and test coefficient draws are disjoint. Training
contains eight even-parity combinations of acquired curriculum, goal, private
belief and tradeoff. Every role marginal and every pair is balanced. Odd-parity
combinations are withheld. Four tests cross old/new combinations with old/new
questions; new questions combine goal and signal interventions. The two question
conditions reuse the identical histories rather than count fresh makers.

Training and development receive full simulator behavior distributions. This is
equal privileged supervision for all learned rivals, not ordinary sampled textual
evidence. Test answers and latent truth remain outside the CPU child's public input
directory. The child imports no generator and writes predictions before the evaluator
scores them. Features have strict schemas and exclude latent state and case identity.

Direct full-history, flat recurrent and three-block recurrent readers each try
widths 24 and 48, seeds 101/211/307, 24 epochs, batches of 128, AdamW learning rate
0.003 and weight decay 0.0001. Integer head sizes match parameter counts as closely
as possible; actual counts are reported. Development loss selects each checkpoint
and capacity. Test loss never changes the budget. Every model may cache its current
encoding. Report training work, maintained state, history storage, query prediction,
and incremental versus full-history encoding separately. Timings are local CPU
measurements, not a hardware-independent operation count.

Exact full-history recomputation uses the declared 24-state prior, not the training
parity restriction, and is labeled as a nominal-family reference. Two predictive
summary references retain the span of passive outcomes or the intervention bank.
Their fixed decoder is minimum-norm state reconstruction followed by nonnegative
normalization. Retained coordinate rank and discarded negative mass are explicit.
Span and likelihood-weighted update closure are checked separately; an arbitrary
predictive bank is never declared sufficient merely because it predicts one task.
The passive goal/belief alias is a planted failure. Neither summary is assumed to
use fewer numbers than the full posterior or to be a recursively sufficient PSR.

Fit seeds, repeated questions and architecture cells are averaged within each
coefficient-draw lineage before uncertainty summaries. Learned role blocks are an
architectural constraint; behavior-only training does not identify their semantics.

## G: actual counterfactual interventions

This separate study uses all sixteen skill-positive latent combinations, including
the combinations withheld in E. Its results cannot be relabeled as E's unseen-
combination generalization. Role zero groups curriculum and tradeoff, role one is
goal, and role two is private belief. Every base/source swap is a valid state in
the explicit generator. Self-swaps are identity controls.

Each architecture cell contains eight training coefficient draws, two development
draws and twenty held-out draws, all disjoint. Each world has all sixteen maker
states with independent 32-observation histories. Training/development use four
deterministically selected sources per base; testing exhausts all sixteen sources
for every base, all three roles and three questions. This gives 73,728 training
pairs and 737,280 test probes, not that many independent observations. Twenty
coefficient-draw clusters remain the independent uncertainty units.

Methods are a behavior-only split state, split interchange training, flat interchange
training with designated coordinates, a direct two-history counterfactual predictor,
and split training with shuffled counterfactual labels. Informed rivals receive the
same additional generator-defined counterfactual targets. For informed methods the
objective equally weights ordinary behavior and counterfactual proper loss; the
behavior-only comparator uses the ordinary target with the same update budget.
The shuffled arm preserves ordinary targets and uses a fixed target permutation.

Use width 24, seeds 401/503, twelve epochs, batch 128, and the same optimizer settings
as E. Match actual parameter counts; retain failed fits and full learning curves.
Test ordinary prediction, correct swaps and wrong-slot mappings. A coherent
coordinate reordering from contiguous to interleaved groups is an exact equivalence
control, not evidence for a unique ontology. An exact independent-pair posterior
reference and a privileged known-state ceiling remain separate. The posterior
reference recognizes self-pairs; it does not exploit the complete test-grid roster
as additional evidence about other makers.

## H: certified finite compression

Three binary summaries of native observations define eight possible histories.
Enumerate all 4,140 deterministic set partitions. At cardinalities 1/2/4/8, select
the flat code minimizing old-question proper loss and the best code restricted to
retaining 0/1/2/3 observation bits. Selection never uses new-question loss. The
maximum storage rate is matched by cardinality; code entropy is reported separately
and is not presumed equal. Product coordinates are observation factors, not mental
roles. The optimum certificate applies only to this finite deterministic class.

Independent observation noise and a half-shared-uniform coupling preserve each
native observation marginal while changing their joint. Twenty coefficient draws
cross all sixteen architecture cells. New-family proper loss averages three query
conditions, removing the constant entropy of the query label. The first discarded
pilot lacked an effective shared-noise factor and included that constant in its
new-family loss; the second pilot repairs these design issues before discovery.

## F: architecture and held-out-law severity

The core factorial varies compensatory/satisficing choice, isolated/interfering
acquisition, external/state-dependent opportunities, and independent/shared source
evidence. Report paired method effects by cell, all four factor contrasts, and all
six pairwise interactions, averaging within coefficient draw. These are fixed
constructed factors, not randomly sampled human architectures. D's source bit is
inactive, so its sixteen slots contain only eight distinct mechanism settings.

A fresh lexicographic law uses twenty new coefficient draws, the eight combinations
of the other factors, all three A access conditions, all eight B change conditions,
and H compression. This is a held-out-law discovery check with 1,920 assigned
evaluations, not a fresh confirmation of the exposed core results. Coefficient
redraws are never called new architectures. E and G also retain all sixteen cells;
fit seeds and repeated probes do not enlarge the architecture sample.

## Repairs, reproducibility and runtime

The first E discovery attempt failed during atomic status replacement under Windows
reader sharing. Its attempted fits and raw input package remain retained. Retry-safe
atomic writes, explicit failed-queue status, unchanged training settings, isolated
regression controls and a new packet identity precede replacement. This is an
instrument repair on reused data, not independent replication. No source used by a
live worker is edited. All failed CPU work remains charged.

Native hidden launches, separate parent/child ownership, optimizer/RNG resume,
hash-bound inputs and weights, strict public test schemas, finite known-answer
controls, independent proper scoring, complete reaggregation and bounded extracted-
source forecast replay establish scoped validity. They do not establish complete
retraining reproducibility, population validity, human learning or unique internal
roles. Deadlines and the cumulative 18 CPU-hour ceiling never reset.
