# Remaining measured-shape dependencies

The full native twin runners, fixed/fresh rival training, complete-world cost
profiles, retained spike-ins and independent reconstruction are implemented.
Small constructed controls exercise full-world export and the pinned engine
backbone. Production admission still requires the measured inputs below. The
numbers in the original commissioning prose are not those measurements.

Supply a JSON object with `source` and `aggregates`. The source records a committed
40-character revision, a SHA-256 for the corresponding locally retained source
file, and a citation. The aggregate keys are defined in `twin_contract.REQUIRED`.
Ghost verifies the actual source bytes and reports empirical-versus-constructed
differences. No raw human text, personal identifiers or demographics are required
in the public reference.

| Twin | Required measured summaries |
|---|---|
| Writing | Maker/session/decision counts, records and sessions per maker, option-count distribution, latency and keystroke quantiles, handling marginals |
| Games | Player count, games per player, move-clock quantiles and moves per game |
| Revisions | Editor count, edits per editor, editors per article, summary coverage and revert fraction |
| Ratings | Rater/item counts, ratings per rater, raters per item, explicit nominal/ordinal semantics and rating marginals |

The current Sounding Line intake census and history-texture report do not supply
every required field. A census is not an outcome-marginal analysis. Ghost has not
read held-out human labels to fill those gaps. These are dependency holds, not
negative mechanism results.

Once an authenticated reference is delivered, the finite twin controller checks
the full grid at the largest cells first, reserves frozen rival fitting and the
complete sixteen-world grid, and admits only work that fits the applicable hash-bound
V23 allocation. New admissions can partition the batch into complete worlds;
an indivisible world or fit above the packet ceiling remains resource-deferred.
A cap failure preserves partial records and ends that admission.
References, controls, sources, engine implementation and fits are hash-bound.

Clock quantiles use `values`; the legacy `seconds` alias is accepted only when
it agrees if both are supplied. The primary T4 reference uses all 123 released
DICES raters. A 104-rater reference alone changes realism comparisons under the
current generator; a scientific sensitivity needs the separately reviewed mapping
described in the [addendum implementation](ADDENDUM_IMPLEMENTATION_2026-10-16.md).

The shared world graph joins maker identities, revision articles and chronology;
the original per-maker public exports remain retained. A single future-query
boundary prevents future labels entering engine fitting. The committed choice
backbone can score constructed handling, moves and nominal ratings. Its public
numeric-option representation is limited and does not match native latent
information. The current engine has no equivalent target for unobserved revision
purpose, so that slot records `TARGET_UNAVAILABLE` rather than inventing observed
intent labels. Product-module admission and real-data module smokes require the
corresponding reviewed ToMpathy modules and their gates. The failed Stage 15
profile witness remains failed until a separately reviewed candidate passes.
