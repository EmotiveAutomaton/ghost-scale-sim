# V21 finite candidate omission

Does expanding an incomplete candidate list improve exact reconstruction? With half the finite catalog omitted and eight expansion slots, evidence ranking raises truth coverage from 57.52% to 90.23% and lowers full-catalog loss by 0.69165 nats versus uniform expansion. The coarser candidate-or-unknown loss worsens instead. This is a supplied-law constructed-method result, not open-world discovery or confirmation.

The [frozen design](C05_OMISSION_ADMISSION.json) has 100 types: ten mechanism families crossed with ten parameter values. Eight development worlds supply positive priors and two noisy ten-category cues, with family reliability 0.8 and parameter reliability 0.6. Each world has 256 cases. There are no fitted seeds. The same cases recur across omission levels and expansion budgets; uncertainty uses 4,096 whole-world resamples, never cases or repeated budgets as independent worlds.

The mechanism rule keeps the first 100, 90, 75 or 50 type identities before outcomes. Uniform expansion follows a fixed training-identity permutation; evidence ranking uses the supplied cue likelihood and stable identity ties. Neither uses test truth. Only the separately labeled truth-supplied diagnostic may add the true type. All methods except forced choice receive the exact aggregate posterior mass of the remaining omitted types and spread it uniformly for full-catalog scoring. This is substantial information privilege: computing that aggregate already consults the complete finite law. It is not learned missing-mechanism detection or a computational saving.

The truth-supplied row uses unavailable labels and is not an admissible competitor; its apparently stronger accuracy reflects that privilege.
