# V21 executable and historical routes

Does reproducing an artifact recover the route actually taken? Every tested route reproduces the endpoint, but the shortest route matches history only 23.63% of the time without a current witness. Using 64 past records raises historical-reader accuracy to 63.87%; equally informed direct enumeration matches it. This is a constructed-method result, not learned superiority or confirmation.

The [frozen E04 design](E04_ROUTES_ADMISSION.json) supplies four programs for each binary goal: set the goal directly; set its opposite then flip; set the goal then flip twice; or set the opposite, inspect, then flip. All execute to the same endpoint. Four latent maker types prefer different programs, under a supplied world-specific policy. The task distinguishes successful production, the actual current program and the next program chosen for the opposite goal. The endpoint reveals the goal in this miniature; it does not reveal the executed route.

Eight development coefficient worlds each contribute 128 cases. Past-history lengths 0, 4, 16 and 64 reuse identical case prefixes. Current observations contain no route witness, an inspection witness, or the full route. Shortest and goal-plausible reconstructions ignore past history. Historical inference integrates maker and route jointly; the independent direct enumeration has identical information. The policy and complete executable catalog are supplied, with no fitted models or law uncertainty integration. These are restricted-information controls, not matched learned architectures. The small increase in confident current-route errors, 0.20 percentage points, remains visible in the full record.

Successful reenactment remains uninformative about route uniqueness: with no witness all four programs have positive posterior probability even after 64 records. For example, setting zero directly and setting one followed by a flip both produce zero; they are distinct executed histories. A prior history changes relative probabilities, while a complete current record identifies the actual program. The independent direct calculation agrees within 1.89e-15; its parity blocks any claim that a maker representation is uniquely necessary.
