# W5 optional WB1 calibration: prospective implementation

This conditional setting is built, not admitted. Only a complete, passing Sounding Line WB1 aggregate received by October 28, 2026 at 19:00 UTC qualifies. The operator reviews the upstream scientific/control receipts, then binds the aggregate to its actual source-result SHA-256. Canonical-source completion or an effects-cost failure is insufficient. No human text enters this adapter.

The normalized input has exactly `schema`, `complete`, `controls_passed`, `effect_basis`, `source`, and `classes`. Schema is `ghost-v25-wb1-aggregate-1`; the flags must both be true and effect basis `standardized_mean`. Source identifies project `SoundingLine`, a stable claim ID and the result SHA-256. Each class has a stable machine ID, positive integer event count and the same roster of at least three finite standardized mean effects. Raw text, missing measures, duplicate classes, non-finite values and late receipts are rejected.

Keep up to six classes by descending event count, breaking ties by ID. Among retained classes select three measures by maximum-minus-minimum spread, breaking ties lexically. Linear one-third/two-thirds quantiles determine 0/0.5/1 effects; equal effects stay together, with equality assigned to the lower bin. No class or feature is invented.

Provisional analyst interpretation, declared before data: the received effects calibrate the constructed world library, and the native true/merged/missing/split readers are compared within that library. This makes a defined comparison when the empirical class count differs from six; the packet supplies no mapping from empirical classes to W1's six arbitrary labels. It does not identify human end weights. Preserve this variant separately from native W5, and revisit the interpretation if the design packet supplies a different mapping before admission.

Use 15 end weights, rationalities 1 and 3, and K+1 nuisance habit states, with a uniform exact-reader prior. Project the four W1 training menus to retained labels and keep distinct nonempty menus. Each world has eight makers and 512 choices, scored at prefixes 8/32/128/512. With one class, merging is unavailable. The primary remains descriptive true-ends log-score loss against the true library at 128 records; report false confidence and zero-support cases separately. A one-class or equal-effect input may be uninformative and is not repaired by inventing spread.

Prepare `v25-w5-calibrated-probe-1` with one complete world at each rationality. Bind inputs, actual receipt time, protocol, controls, immutable source and environment. Admission still enforces the W5, study-pool and Gear 2 ceilings. Never reuse the completed native W5 identity or overwrite its primary report.
