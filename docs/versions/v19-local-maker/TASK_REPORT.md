# E2: task measures, skill and hidden evidence

Does the apparent skill benefit reverse with the task objective? No reversal appears: display-on success is exactly 50% in every purpose/skill group because complementary paths have equal probability. Hiding final evidence modestly worsens purpose inference. This is a constructed-method and model-mechanism result, miniature — architecture untested; the symmetric task measure cannot establish a presentation-skill benefit or human intent.

This is complete probability-weighted enumeration of 110,592 trajectories in
eight admitted local worlds, with no new samples or fits. Functional success
requires claim-on with matching evidence; presentation success requires display-on.
Both are stipulated evaluation functions, not inferred intentions. The maker's
governing purpose and its skill are distinct from the reader's competence.

a skill benefit in this population. Task functions disagree on about half of
trajectory probability, but that is not a reversal of the aggregate skill ranking.

**Post-result symmetry diagnostic:** complement all three initial artifact bits
and the undo buffer, keeping maker, requested purpose and goal/operation sequence
fixed. Claim/evidence disagreement and every goal-choice weight remain unchanged;
each legal operation commutes with complement. The two initial artifact contexts
have equal prior weight. Each display-on trajectory therefore has an equally
probable display-off partner within the same maker. All 55,296 retained path pairs
verify this with zero probability difference. This explains the exact half and
exposes the success measure's lack of sensitivity here. It does not mean that
governing purpose fails to change presentation choices. No scoring rule was changed.
