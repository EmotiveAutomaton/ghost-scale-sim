# Query-schedule likelihood envelope: prepared independent alternative

Does a known query schedule tighten the universal likelihood-rounding bound?
The universal bound permits the most fragile query context at every step. This
alternative conditions only on the already supplied, outcome-independent query
schedule; it never chooses a schedule using rounded-law errors.

Use the same eight retained laws and all three storage precisions. Freeze two
mechanical context schedules for lengths 8/32/128: repeat contexts 0,1,2,3, and
repeat contexts 3,2,1,0. These balanced schedules are specified before outcome
consumption. For each context take the largest supported endpoint log-ratio
range; sum those ranges along each schedule and apply tanh(sum/4). Compare the
universal bound, this context-conditioned bound, and its exact constant-range
identity control. All statewise ratios, attaining endpoint sets, exact supports
and individual law summaries remain retained. Cast support loss remains an
unbounded observation possibility, never a floored value.

The observation-independent schedule supplies no new evidence. Equal schedule
counts must give identical bounds even when their order differs; this ruler does
not measure transition-dependent order effects. Compare scalar log sums and
explicit small likelihood products; permutation, constant-range, support-loss,
and deliberately undersized-bound controls must pass. Complete-support timing,
source freeze, original and both full replays, independent reconstruction and
equal-law regroup are required. No new observations, fits or protected lineages.

Prepared, unimplemented and unadmitted. The separate 1,800 CPU-second inclusive
cap covers controls, failures, executions and review within existing ceilings.
This asks whether known query composition improves a conservative error ruler;
it does not establish realized error, reachability, learned access or process
correspondence. If the bound does not tighten, retain that finite identity and
do not add schedules merely for occupancy.
