# Goal localization as a decision: prepared independent alternative

Does selecting a joint modal path sacrifice per-step goal localization even when
the same forecast has useful marginals? This finite D-family diagnostic separates
the forecast from the action taken with it. It is implemented and source admitted under [the frozen execution contract](GOAL_DECISION_ADMISSION_PROTOCOL.md); numerical acceptance remains pending.

Use the accepted restricted and goal-product forecasts under complete operation
witnesses, all four readouts, budgets, sixteen development lineages, two draws and
five seeds. Compare the highest-probability joint goal path with the tuple of
highest-probability single-step goals. Both choices must belong to the complete
27-path public operation-compatible space. Native support never constrains the
choice. Keep the same frozen forecast: prediction loss is an identity control.

Score mean per-step goal accuracy, complete-goal-path accuracy, incompatibility
with native positive support and expected forecast Hamming loss (the fraction
of incorrect step labels). Native rulers separately verify that coordinatewise
modes minimize forecast Hamming loss and joint modes maximize whole-path accuracy.
These are different decision objectives, not contradictory validity gates.

Tie handling is fixed smallest full-label order for both choices; retain exact
tie frequencies and margins. Do not claim a numerical tie effect without checking
the competing masses. Use every packet and paired 10,000 sixteen-lineage bootstrap
draws with seed 191011, retaining draw/seed variation. No new fit, sample or
protected lineage. Freeze before outcomes and require known answers with opposing
optimal decisions, equal-marginal/different-joint paths, ties, full roster and
reader leakage tests, both complete replays and independent reconstruction.

The separate inclusive 1,800 CPU-second D-family cap requires timing admission
within existing family and global ceilings. This is a constructed-method decision
comparison; useful localization is not proof that a historical goal path occurred.
