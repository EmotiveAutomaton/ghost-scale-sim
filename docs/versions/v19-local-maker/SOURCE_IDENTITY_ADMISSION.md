# Unknown retrospective source identity: implementation contract

This implements the prepared source-identity alternative. Keep all 28,672 retained
posterior rows, eight laws, both evidence conditions, two observation draws and
seven available horizon/checkpoint cells. All 48 unavailable strata remain absent.
Every distinct true source is an equally likely candidate; repeated copies of the
same identity do not add candidates. Evaluate all eight report endpoints at the
existing copying probabilities 0, 1/4, 1/2, 3/4 and 1. No new observations or fits.

The exact account averages source-specific likelihoods before normalizing. Its
posterior source weights are proportional to the observed report likelihood. The
uniform rival averages separately normalized posteriors over **compatible** sources.
Impossible source/report pairs have no normalized posterior: exclude them explicitly
and retain their fraction and exact source probabilities. A most-recent-source
rival uses the source with largest original observation time; unsupported reports
remain separate support-failure probability mass, with undefined raw errors.

For each endpoint retain report probability, complete posterior source weights,
source support, inverse-normalization coefficients, source entropy and each rival's
future-schedule total variation, largest future-coordinate discrepancy and mean
future total variation. The latter evaluates every remaining time, context and
endpoint. Probability-weighted error mass and supported probability mass are
separate; their quotient is conditional error only when support is positive.
Exact full posteriors, true source identities and supplied laws remain immutable
inputs. Together with raw source coefficients they reconstruct every hypothesis
posterior and future coordinate. Raw NaN means unsupported, never zero error.

The source-identity uncertainty belongs inside each posterior row. Do not average
source-level errors as though the source were known. Average report discrepancies
under the exact marginalized report law, then all 128 rows equally within each
draw, both draws equally within each of eight equally weighted laws. Preserve
lineage/evidence/horizon/checkpoint/draw/copy-probability strata. No practical
threshold or confidence interval is prescribed; this is an exploratory exact-law
diagnostic, miniature — architecture untested beyond the retained roster.

Require direct scalar full-hypothesis Bayes tests at every future coordinate,
single-source/equal-likelihood identities, constant and sparse laws, unequal-source
likelihood positive controls, duplicate-source rejection, impossible reports,
source permutation invariance, normalized mass checks, and complete input-binding
integration. Full-support synthetic timing includes raw serialization and must
fit the prospective inclusive 3,600 CPU-second card, both complete replays,
independent reconstruction and existing B/global limits. If timing blocks complete
support, preserve the failure; no sampled sources or seed padding.

Source identities and source prior are supplied, not inferred from public text.
All exports are scientific/evaluator evidence; no new reader input. Two-report
dependence and source-identity disclosure value remain independent alternatives.
