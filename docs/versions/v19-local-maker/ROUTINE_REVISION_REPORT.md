# Routine and current-request revision: complete replay, numerical review pending

Does a fixed revision opportunity distinguish retaining a prior routine from adopting the current request? The five-policy comparison and both complete replays match all 27 deterministic outputs, covering 110,592 native paths and 171,520 revision comparisons. Its 200 anonymous reader packets contain observed requests and visible artifacts only. Independent numerical reconstruction is source-frozen before accepting success or cost differences. This is a constructed-method reproducibility result; learned competence, historical process correspondence and human endorsement remain unestablished.

The question is whether one explicit inspection/revision opportunity separates
an unchanged productive routine from the current observed request. Five fixed
policies compare keeping the artifact, native goal selection, explicit adoption
of the request, a visible-task optimizer and a full-state task oracle. The latter
two receive skill and belief mechanics; they are privileged references. Adoption
is an intervention on governing purpose, not something inferred from an action.
This experiment does not train a maker or establish learned expertise.

The original three-step episodes remain unchanged. All 13,824 paths on each of
eight original admission lineages are retained, including native probabilities.
Only identical full revision states are collapsed. There are 8,576 such states;
every source index survives in the separate evaluator records. Each state crosses
unchanged/changed request, intact/hidden presentation and five policies, giving
171,520 comparisons and 1,280 aggregate strata. Goal selection precedes native
operations. Undo uses the artifact before the third original operation.

Success, net success after stipulated costs, operation cost, revision rate,
repaired failure and destroyed success are separate outcomes. Inspection costs
0.01 success units and each non-inspect operation costs 0.05. Keeping the artifact
has neither cost. Those numbers are experimental choices, not human preferences.
The hidden-presentation reference integrates independent fair bits for current
and undo artifacts. Its prior is not an empirically calibrated observation model.

All 27 deterministic files match original, adjacent and extracted-source runs.
All 417 original frozen sources, eight input blocks, plans, source archives and
environment records verify. Timing is bound separately for each execution and
is not required to repeat. No science was restarted to obtain this review.
The original controls pass, but replay identity alone cannot rule out a shared
implementation error. Numerical advantages are therefore not adjudicated here.
