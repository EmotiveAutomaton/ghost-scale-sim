# Changed-tool support transfer: replay verified, numerical review pending

Does a learned composition advantage survive a changed primitive operation? The frozen-table transfer comparison and both complete replays match all 47 deterministic outputs across 221,184 native paths and 327,680 scored rows. Independent count, path, forecast, score and paired-lineage reconstruction is source-frozen before accepting numerical transfer differences. This is a constructed-method reproducibility result; supplied skills, beliefs and operations make it forward prediction, not historical process reconstruction or human intent.

The experiment reuses both saved training draws and both original/composition-holdout
count tables. No fit occurs. Seven fixed methods comprise direct endpoint counts,
nearest-query retrieval, exact learned transition propagation, one/four/sixteen
sampled learned paths and an original-law oracle. A separate true-law oracle is
an explicitly privileged reference. All distributions use the same final 1/32
uniform mixture; a wrong deterministic answer has probability 1/256. No method
or support subgroup is selected after outcomes.

Eight previously evaluated coefficient lineages supply both original and changed
tool populations. These are not untouched confirmation lineages. All 640 queries
supply skill, belief, initial artifact and three requested operations. This task
does not infer the actual operations or local goals from an artifact.

The 7,680 strata cross both rules, both draws, both fit modes, eight methods,
all/changed/stay endpoints and five original-law support groups. Those groups are
all queries, seen queries, unseen queries, withheld action composition and withheld
composition whose original-law primitives were visited. An original-law primitive
being visited does not mean the changed transition was seen. Empty cells retain
zero mass and undefined conditional scores.

Logarithmic loss measures probability assigned to the true endpoint in natural-log
units. Squared probability error and true-endpoint probability are separate scores.
Native path probability supplies weights within each stratum. Cross-rule contrasts
include changed population weights, and do not alone isolate a matched-query effect.
The fixed 0.02-nat practical margin is unchanged. Numerical advantages, reversals
and equivalence remain pending independent reconstruction.

All 47 deterministic outputs agree across original, adjacent and extracted-source
executions. Every source, plan, input and execution-specific timing binding verifies.
The producer has 439 frozen sources and 13 parent inputs. It reproduces every saved
parent forecast, support assignment and original-law aggregate before transfer.
That reproduction is an identity control, never another independent observation.
Replay agreement cannot exclude a shared implementation error.

The independent checker reconstructs both count fits from ordered saved training
episodes. It reuses the validated independent native executor and explicit sum over
all intermediate paths, without importing producer forecast or score routines.
It reconstructs both rule populations, all uniforms, forecasts, support and changed/
stay assignments, raw scores, denominators and parent identities. Its regroup reports
every fixed method against direct prediction and every changed-rule/original-rule
contrast. Two draws are averaged within lineage; eight paired lineages are the
uncertainty units, with 10,000 bootstrap resamples and separate draw means.

Eight isolated tests pass in 18.64 seconds, including a complete two-rule native
fixture, paired draw-within-lineage regrouping, explicit empty strata and deliberate
forecast corruption. The checker has 442 frozen sources and 53 frozen completed
inputs. Admission is not successful campaign verification.

support label, lineage, population weight or result. SCIENTIFIC_EVALUATOR.zip retains
all native paths, raw scores, count models, forecasts, uniforms, parent inputs,
