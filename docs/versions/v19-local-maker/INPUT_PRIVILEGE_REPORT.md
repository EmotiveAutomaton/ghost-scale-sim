# Hidden mechanic metadata: independently verified

We tested how much exact endpoint prediction depends on supplied skill and belief. Hiding both creates mechanically ambiguous evidence in 102 of 248 original-tool groups and 120 of 248 changed-tool groups; only 64 and 82 groups have multiple endpoints with positive native support. Independent reconstruction and both complete replays verify this constructed-method input-privilege limit. It does not establish learned access, historical process correspondence or human intent.

The retained 640 queries specify an initial three-unit artifact and a complete
three-operation sequence. Full queries also specify the maker's skill and belief
error. Removing either or both fields groups queries by identical visible inputs.
All mechanically legal hidden-field completions are enumerated, including those
excluded by the retained policy's support. Unskilled tool use remains illegal.
There is no learned reader, new fit, sampled episode or reserved lineage here.

The native-law prediction is an explicitly supplied-law oracle. Its native loss
equals conditional endpoint entropy: residual uncertainty after the visible query.
With both fields hidden, this is 0.14366 nats under the original tool and 0.18483
under the changed tool. Even the exact native-law reader cannot recover a unique
endpoint in every native-supported group. Better prediction from full metadata
therefore reflects real input privilege, independently of learned-model quality.

The original admission passed 12 isolated controls; the independent checker
passed 24 including runtime/portable dispatch. It exercises known ambiguity,
