# Learned dependence between steps: execution and replay verified

We tested whether dependence between steps improves frozen joint-process prediction. All 1,994 deterministic files match across the original run and both complete replays. The independent checker passes 35 controls and has begun execution; numerical acceptance remains pending. This is a constructed-method diagnostic, not evidence of historical process correspondence or human intent.

Each frozen forecast assigns probability to 5,832 complete three-step paths.
The diagnostic sums three eighteen-way distributions, each pairing a local goal
with the operation at the same step, then multiplies those distributions across
steps. This retains dependence within a step while removing dependence between
steps. The product can assign probability to incompatible paths; it receives no
support restriction based on public mechanics or native truth. Unknown probability
remains distributed across the full label universe.

The original roster is unchanged: four evidence tiers, budgets of 32, 128, 512
and 2,048 labels, sixteen development laws, two training draws, five feature seeds
and four readouts: raw history, frozen latent state, predictive bank and matched
frequencies. Native posterior products are separate evaluator references. There

natural logarithm of forecast probability. The contrast is product loss minus
original loss; positive values favor the joint forecast. Squared error, excess
over native uncertainty, compatible mass, candidate coverage and size, unsupported
modal claims, confidence, abstention, unknown mass and each step's goal/operation
accuracy remain distinct. This comparison does not replace the primary learning
contrast or establish that a predicted process historically occurred.
