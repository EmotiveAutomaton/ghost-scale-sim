# Time-balanced source retention: prepared independent alternative

At the same source count, does covering earlier and later source times preserve
retrospective information better than retaining only the newest sources? This
unimplemented alternative isolates temporal coverage from context coverage. It is
independent of a favorable context-balanced result.

Use the same retained eight laws, two evidence conditions, two draws and complete
posterior/source roster. For each half/quarter recency count k among n sources,
retain sorted-time ranks floor((j+0.5)*n/k) for j=0,...,k-1, using zero-based ranks;
for k=0 retain none. Selection depends only on source times and the fixed count.
Retain original source probabilities, complete copy counts and an explicit
uniform-maker-prior remainder for every omitted source. Compare full retention,
recency, and this fixed evenly spaced roster; there is no parameter search.

Enumerate all endpoint reports and existing copy probabilities. Keep exact support,
proper squared regret, largest future probability error, group total variation,
retained identities and actual float/integer storage separate. All posterior and
source identities, paired draws and equally weighted laws remain. No new fit,
observation or protected lineage. Require scalar Bayes, matched-count and unique
selection checks, equal-roster/constant-law identities, an older informative source,
source-order permutation with times fixed and deliberately removed remainder mass.

Prepared only: implementation, complete-support timing, controls, frozen source,
two complete replays and independent reconstruction are required before acceptance.
Prospective inclusive cap is 3,600 CPU seconds within existing family/global limits.
No source sampling if complete support is intractable. Two-report dependence remains
a separate prepared alternative.
