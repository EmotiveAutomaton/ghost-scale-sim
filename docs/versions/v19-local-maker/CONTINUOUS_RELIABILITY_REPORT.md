The continuous interval adds no coordinate extrema or total-variation diameter beyond the compatible finite-set endpoints; 4,224 impossible truthful endpoints are excluded. For each reply, endpoint masses split into nonnegative matching and nonmatching
parts. Conditioning on reliability from one half through one gives a normalized
fractional-linear curve. The real-valued algebra in the admission contract shows

An arbitrary fallback at an impossible observation never enlarges this segment.
Coordinate extrema and total-variation diameter are set properties; the upper
coordinate envelope is not silently normalized into a chosen point forecast.
