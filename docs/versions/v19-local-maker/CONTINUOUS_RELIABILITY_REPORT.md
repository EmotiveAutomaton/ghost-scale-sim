# Continuous reply reliability: execution and complete replay verified

We tested whether endpoint forecasts bound every intermediate reliability of a binary reply. All 71 deterministic files match across the original run and both complete replays. The independent scalar checker passes 26 controls and is source admitted; numerical acceptance remains pending. This is a supplied-law constructed-method certificate, not evidence of learned access or historical process correspondence.

The frozen comparison retains 640 queries, eight development laws, original and
changed tools, and native and uniform legal conditional models. Every visible
group, both requested fields and both possible replies are enumerated. It uses
no new fitted model, episode, selected subset or protected confirmation lineage.
The same conditional inputs underlie the accepted finite-reliability experiment.

For each reply, endpoint masses split into nonnegative matching and nonmatching
parts. Conditioning on reliability from one half through one gives a normalized
fractional-linear curve. The real-valued algebra in the admission contract shows
that this curve traces the segment between its half-reliable and truthful
forecasts when the truthful reply is possible. If the truthful reply has zero
support, that endpoint is excluded and the constant left limit is retained.
An arbitrary fallback at an impossible observation never enlarges this segment.
Coordinate extrema and total-variation diameter are set properties; the upper
coordinate envelope is not silently normalized into a chosen point forecast.

The 17 rational grid points check numerical implementation, not the continuum
theorem. Exact binary64 equality, the 1e-12 reconstruction tolerance, and the
real-valued proof are distinct. There is no new reliability prior or decision
ranking. The stored grid includes zero-vector placeholders only where explicit
compatibility masks mark impossible replies; these are not forecasts.

All 71 deterministic files match across original, adjacent-source and complete
extracted-source executions. All 595 source files, 34 input bindings, source
archives, plan and environment identities, and execution measurements verify.
