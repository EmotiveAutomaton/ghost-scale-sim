# Independent single-report aggregate-state review

Before accepting numerical results, reconstruct the joint future-group/report
mass by summing each source's group/past-state table against its supplied law.
Separately form full-hypothesis report likelihoods, weight and normalize them.
Decode bit schedules independently; use indexed state-change accumulation to
check every future time, context and endpoint. No producer acquisition, update,
summary, grouping or sparse-transition kernel is imported.

Check all retained group masses, joint report masses, source identities, integer
copy counts, report probabilities, exact supports, undefined masks and total
variation. Count structural state sets explicitly, including all float and
integer costs and separately shared law/schedule values. Rounding-scale errors
are compared at the existing one-trillionth absolute tolerance. No new threshold
is selected from native results. A separate standard-library regroup must use
the original 143,360 summary rows, all 19 metrics and all 128 Cartesian identities
per draw, with two draws inside each of eight equally weighted laws.

Known-answer checks include informative and constant laws, certain copying,
sparse/disjoint support, source permutations and corruption of every raw field,
source pairing, summary coverage and timing denominators. Freeze and test in an
isolated checkout before the existing single-worker queue executes the review.
All review work is charged to the original 3,600 CPU-second card and the existing
family/global ceilings. No new fit, observation or protected lineage is used.

Scope is one report under a fixed source prior and supplied law. Numerical
sufficiency does not establish minimum storage, optimized query latency, learned
access, historical process correspondence or human intent. Scientific/evaluator
outputs stay separate from reader inputs, which are unchanged.
