# Joint noisy replies: numerical result verified

We tested whether joint dependence between noisy replies matters when each field has the same marginal reliability. For two 75%-accurate replies sharing one error, accounting for their dependence reduces forecast loss by 0.05482 nats on original tools and 0.08822 on changed tools compared with treating them as independent. Independent reconstruction, all 7,488 paired estimates and both complete replays verify this supplied-law constructed-method result; learned access, historical process correspondence and human intent remain unestablished.

The comparison fixes 640 queries, eight development laws, original and changed
tools, native and uniform legal-completion conditional laws, and native and
equal-query scoring populations. Skill alone, belief alone, both fields and no
request are evaluated at marginal accuracy 0.75. Actual errors are independent
across the two fields or share one flip. The reader either uses the joint channel
or multiplies its identical marginals. No field is selected from truth or losses;
no fit, episode or protected lineage is consumed.

Independent errors and shared errors have the same single-field likelihoods.
Single-field and no-request comparisons therefore agree. The shared flip preserves
the relation between the two bits: both can be wrong while their parity remains
right. This is a stipulated channel property, not a general advantage of correlated
evidence. Ignoring that relation loses information on the declared endpoint task.
Under native laws and native weights, correctly modeled shared replies improve
loss over no request by 0.08171 nats on original tools and 0.12289 on changed tools;
independent replies improve it by 0.02508 and 0.03285 respectively.

Request prices remain 0, 0.02 and 0.1 nats per returned field. Equal two-field

shared-channel gains over no request survive, while independent-channel gains
reverse. At 0.1, both cost-adjusted comparisons lose to no request. Stipulated
prices are not measured human preferences. Squared forecast error, true-endpoint
probability, residual ambiguity and request counts remain separate outcomes.
