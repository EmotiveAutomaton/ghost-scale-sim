# Public requested-purpose calibration: executable contract

Does averaging over public task requests conceal opposing errors in local-goal
probabilities? This implements the prepared declared-purpose diagnostic. Requested
purpose is an observed request; it does not establish the maker's adopted purpose.
The accepted goal-decision forecasts remain fixed: sixteen development laws, two
training draws, five fit seeds, four budgets, four readouts, two forecasts, three
local goals and three positions. Keep native and equal-frame populations separate.
No new fit, samples, model setting or protected lineage is used.

Use only the two legal integer requested-purpose values in each public packet.
Retain both groups even when empty and use the same request group at each position.
Reject invalid values and evaluator fields. The grouping must be invariant to
visible artifact and witnessed operation changes when the request stays fixed.
Hidden governing purpose, goal labels and correctness never choose a group.

Freeze ten integer-tenth probability bins. Retain raw binary64 probabilities and
every joint group/bin weight, forecast sum and native-correctness sum before division.
Preserve group masses, conditional signed errors and NaN means exactly at zero
weight. Pooled discrepancy takes absolute values after summing request groups;
grouped discrepancy takes them before summation. Their difference diagnoses
cancellation without changing forecasts or evidence. Summing requests must reproduce
the ungrouped sufficient sums; native self-forecasts must calibrate exactly.

Save all 320 array bundles, 92,160 rows, 225,280 frame forecasts, 704 unchanged public
packets and 5,120 parent loss/accuracy identities. Seed 191018 fixes 10,000 paired
resamples of sixteen laws, keeping two draws and five seeds inside each law. Preserve
576 means, 576 within-readout cancellation estimates, 1,296 paired budget contrasts
and 324 normalized log-budget areas. Intervals condition on retained fits. No new
practical-impact threshold or architecture ranking is introduced.

Known opposite and identical errors, one-group identity, empty groups, native self,
scalar sums, permutations, bin boundaries, mass conservation, exhaustive public
request assignment, complete synthetic execution and corruptions precede admission.
Check native and portable dispatch. Freeze source, inputs, plan and environment
only after full-size synthetic timing admits original execution, both complete
replays, independent reconstruction, controls, failures and operating work inside
the inclusive 1,800 CPU-second D card. No implicit extension or partial roster.

Numerical acceptance requires independent reconstruction of every group/bin array,
parent identity and paired estimate plus a third direct-index regroup. Execution
and replay acceptance remain separate. Reader inputs are separately archived from
scientific/evaluator forecasts, targets and rebuilt arrays. This is exploratory
constructed-method calibration, miniature — architecture untested beyond the
admitted roster. Historical purpose adoption and human intent remain unestablished.
Retrospective updating and fixed-bin resolution sensitivity are two independently
prepared alternatives; neither is represented as an implemented handler.
