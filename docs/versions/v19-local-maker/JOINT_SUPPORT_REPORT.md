# Public execution support: execution and complete replay verified

We tested whether public execution constraints improve frozen joint-process readouts. All 1,457 deterministic files match across the original run and both complete replays. The independent checker passes 21 controls and has completed execution; numerical acceptance remains pending. This is a supplied-mechanics constructed-method comparison; mechanical legality does not establish historical process correspondence.

The comparison retains all frozen joint-process forecasts: four evidence tiers,
four nested training budgets, two training draws, five feature seeds and sixteen
development lineages. The three learned arms, same-budget frequency baseline
and their support restrictions share exactly the same public mechanics. A uniform
legal-support baseline measures what those mechanics supply without learning.
No model is fitted, no episode sampled and no protected lineage consumed.

Every hidden initial binary triple, both skill and belief-error bits, and every
legal three-operation sequence enter the support enumeration. Each operation
path retains all 27 local-goal assignments. Purpose, routine, native controller
rules and posterior mass cannot remove a goal. Complete operation witnesses
therefore supply operations while leaving goals unresolved. The reader packets
are unchanged; even the native population's restricted start set is not supplied
to artifact-only support construction.

The original unknown tail is expanded over all unseen labels before restriction.
An empty mask or zero retained mass is a failure with an explicitly retained
original fallback. Candidate sets rank the full 5,832-label universe; observed
alphabet labels precede unseen labels at exact ties. Native posterior compatibility
is narrower than mechanical legality and is scored separately. No forecast gain
is accepted merely because a path satisfies the mechanics.

All 1,457 deterministic files are identical across original, adjacent-source and
complete extracted-source executions. All 603 original source bindings, 1,285
input bindings, source archives, environment fingerprints and output/timing hashes
verify. The producer's original-number reproduction receipt is preserved; its
numerical contents remain subject to independent adjudication.

The independent checker passes 21 isolated controls without warnings or skips.
It uses a third scalar mechanics implementation and imports no producer mechanics,
support, score or regroup function. It enumerates every mask, independently sums
each legal normalization factor, then scores the actual saved binary64 normalizers
so discrete candidate decisions refer to the executed forecasts. Sparse frame-local
truth sums and native weighting reconstruct all 10,240 original strata and all
23,040 support-comparison strata. Its frozen uncertainty calculation averages
draws/seeds within lineage before the declared 10,000 paired resamples, preserving
all 128 budget contrasts, 32 learning areas and draw/seed variation.

Known answers cover hidden starts, all-goal retention, request invariance, tool
and undo semantics, private fields, impossible witnesses, empty/zero-mass fallback,
unknown-only support, exact ties, native-versus-legal compatibility, scalar proper
scores, excluded truth and an end-to-end synthetic fixture with corruption detection.

through the existing serial queue at below-normal priority with one numerical thread.
