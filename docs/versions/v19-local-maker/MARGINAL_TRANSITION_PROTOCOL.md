# Current-maker marginals and future changes: prepared independent alternative

Does preserving the current maker distribution preserve predictions after a
possible future change? This finite B-family diagnostic is independent of
checkpoint truncation and primitive-feedback outcomes. The handler is implemented;
isolated controls and source-bound admission precede execution. No outcome is
claimed. It tests a structural representation limit, not learned access.

Use the frozen unknown-time/type hypothesis roster, both horizons 32/128,
checkpoints 8/16/17/20/32 where in range, and subsequent query steps through the
same horizon. For every current maker, enumerate pairs of complete hypotheses
that project to that maker now but to different makers later. Give each candidate
pair the identical current point mass, and compare its separately projected
future endpoint forecasts under all eight admitted development laws and four
contexts. Retain every pair, including forecast aliases; no best witness selection
or new observation draws. Count distinct state-projection and forecast differences.

Retain the complete pair enumeration in lossless Cartesian blocks. For each
checkpoint and every later step (including the checkpoint identity control),
partition hypothesis indices by current and future maker. Every two groups
sharing the current maker define all cross-product pairs; every unordered pair
occurs once within that time cell. Save full memberships, counts and schedules.
The law is stored once per lineage, future-state pair and context, so repeated
identical forecasts are not copied millions of times. This is a storage format,
not pair subsampling. Report all time cells and contexts, including zero-pair
cells and forecast aliases. Count hypothesis-pair/time instances separately from
unique independent evidence; there are no new evidence samples.

maximum absolute difference, exact binary64 equality and the fixed 1e-12 display
tolerance separately. Binary64 equality is not an exact symbolic-law certificate.
