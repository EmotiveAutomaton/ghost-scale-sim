# Independent bounded-retention reconstruction

Reconstruct every window from source-wise Bayes factors and independently decoded
bit schedules. Keep all original source mass. Recent sources contribute their
joint past-state/future-group numerator; forgotten sources contribute the original
uniform sixteen-maker prior likelihood times current group mass. Copy counts
include every source. Compute group/report numerators directly, then every future
time, context and endpoint. No producer evaluator, summarizer, transition matrix
or posterior-direction kernel is imported.

Explicit expected one-hot squared losses independently check regret against full
retention. Check report probabilities, exact support, NaN masks, future probability
errors, group total variation, retained identities, forgotten mass and histograms.
Recount structural joint cells from sets of group/past-state pairs, distinguishing
mixed cells from deterministic cells that reuse group weights. Float64, int32 and
shared prior storage remain separate. Reference execution is not optimized compact
state latency. Every saved field must have an independent reconstruction.

Bind all frozen inputs, source, plan, environment, outputs and timings. Retain all
28,672 posteriors, 505,856 sources, five copying probabilities and eight reports
under four windows. Preserve eight laws, both evidence conditions, two draws and
all 48 unavailable strata. Reconstruct 143,360 original summary rows and 1,120
paired draw strata, each with 128 Cartesian identities. A separate event review
regroups ORIGINAL rows into 560 law strata and 70 population cells, with two draws
inside each law and eight equally weighted laws. Windows and reports are paired
measurements, not independent laws.

Controls include dense, sparse, constant and disjoint laws; a single source;
source permutation with original times; full-retention and certain-copy identities;
an older informative source; and corruptions of every raw field, NaN/support mask,
summary, source pairing, roster, timing and binding. Test full native integration
and existing portable dispatch. Complete-support synthetic timing includes archive
decompression for all seven structural cells and both source densities before
admission. All preparation, failures, three executions, checker and final regroup
remain inside the original 3,600 CPU-second card and existing family/global caps.
No new fit, observation or protected lineage. Numerical acceptance awaits checker
completion and separate regroup; practical importance remains inconclusive without
a frozen margin and confirmatory precision. This is a supplied-law method test,
not learned provenance, historical correspondence or human-intent evidence.
