# Less specific goal reports: prepared independent alternative

Can reporting a broader goal class preserve useful coverage when precise local
goals remain ambiguous? This D-family alternative is prepared, unimplemented and
independent of any favorable abstention result. It reuses accepted witnessed-goal
forecasts and the full paired roster without fitting or sampling.

Freeze all three two-class partitions of the native goal vocabulary: meaning
versus dependency-or-presentation; dependency versus meaning-or-presentation;
presentation versus meaning-or-dependency. Do not select a favorable partition.
For each, sum forecast probabilities exactly into the eight coarse three-step
paths. Compare mapping the fine coordinate choice into its coarse class with
choosing the coarse marginal mode. Include the fine three-class and one-class
report as specificity endpoints. A broad disjunction never counts as identifying
a fine goal. Report fine alternatives per claim alongside coarse accuracy.

At each of the already fixed abstention costs 0.1, 0.25 and 0.5, compare always
reporting and independent-step abstention under each forecast's own coarse error
cost. Ties abstain and exact modal ties use the smaller class code. Retain all
partitions, separate specificity levels, coverage, incorrect claims, conditional
error, native expected cost, incompatible partial reports and loss. Truth only
scores; it never selects the partition, report, probability or threshold.

Use sixteen development lineages, two training draws, five fit seeds, four budgets
and four inherited readouts with both accepted goal forecasts. Preserve original
fine loss as an identity control and separately score coarse predictive loss.
Paired bootstrap seed 191013 with 10,000 resamples retains draws/seeds within each
lineage. Controls include all partitions, mass conservation, one-class certainty,
known broad-but-wrong fine reports, marginal-mode noncommutation, abstention
boundaries, zero coverage, complete roster and deliberately corrupt reader fields.

The inclusive cap is 1,800 D-family CPU seconds, including synthetic timing,
controls, failures, original, two complete replays and independent reconstruction.
Require tractability before source admission; no approximate or sampled substitute.
No protected lineage, tiny setting or new scientific owner is admitted. Reader
packets stay unchanged; every forecast and target remains scientific/evaluator.
This tests a stipulated specificity-coverage tradeoff in a constructed method,
not historical fine-goal recovery, human intent or universal user preferences.
