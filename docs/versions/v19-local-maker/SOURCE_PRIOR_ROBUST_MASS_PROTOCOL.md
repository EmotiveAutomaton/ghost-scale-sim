# Retained mass with an uncertain source prior: prepared alternative

Can one fixed retained set protect source probability when the source prior is
unknown? The prior-specific mass frontier assumes its weights are supplied.
This independent alternative retains that information gap explicitly. It uses
the same frozen source-time rosters, structural costs and two weighted-schema
byte budgets. No endpoint, forecast, new history, fit or protected lineage.

Before outcome consumption, freeze the uncertainty set as every convex mixture
of the three declared uniform, time-proportional and reciprocal-time source
priors. Retain the recency set and each prior's probability-greedy,
probability-per-byte-greedy and exact-optimum set as a finite candidate library.
Deduplicate identical masks without deleting their policy identities. Choose the
candidate with the greatest worst-case retained probability over the three
extreme priors; ties use the existing recent-time bit-vector rule. The minimum
over this convex uncertainty set occurs at an extreme prior, so no random prior
sampling is needed. This is a candidate-library robust choice, not a claim of
unrestricted minimax knapsack optimality.

Compare every candidate's retained mass under all three priors, the robust
candidate's minimum mass, its prior-specific regret relative to each exact mass
optimum, and the range of optimal-choice identities. Preserve complete masks,
integer bytes and exact rational masses. Original rows retain law/evidence/draw
pairing and equal-law summaries; repeated rosters do not create new populations.

Controls must include independent exhaustive small candidate libraries, all
convex two-prior mixtures on a fixed rational grid, equal-prior and all-fit
identity, a case where a supplied-prior winner is a poor robust choice, permuted
prior/item labels and a corrupted prior normalization. Verify complete input
bindings, all choices, original and two full replays, independent rational
reconstruction and original-row regroup before accepting a finding.

Prepared, unimplemented and unadmitted. The separate 1,800 CPU-second inclusive
cap competes within existing family/global limits and covers controls, failures,
all executions, reconstruction and write-through. Require complete-support
timing and source freeze. This is a storage decision under declared uncertainty,
not forecast optimality, learned provenance, historical correspondence or human
intent. Prior comparisons and their ceilings remain unchanged.
