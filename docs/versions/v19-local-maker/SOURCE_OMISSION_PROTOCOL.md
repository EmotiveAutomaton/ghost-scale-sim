# Source identity omission with frozen filters

Does counting copied observations as distinct sources damage prediction or
current-state uncertainty? This implements the independent alternative specified
in CHANGE_TIMING_PROTOCOL.md before its numerical adjudication.

Use the saved midpoint/stationary streams of G19-B-unknown-change-1: eight
coefficient lineages, two original draws, all sixteen makers, both lengths
32/128, both purpose/skill reference families, changed/stationary and copied/
independent conditions, and every original checkpoint. Reconstruct the parent
stream identities, forecasts, scores and maker-averaged cells before comparison.
Parent controls are identities, never new replicates. No new observations,
seeds, fit, tiny setting or protected lineage are used.

Replace source identity by observation-position identity. Change nothing else:
observed context/endpoint, observation time and original source time remain
fixed. Thus this is identity-only omission, not complete provenance blindness.
Repeated timestamps or content could support dependence inference by another
reader; these frozen filters treat supplied identities as independent. Preserve
true identity in evaluator inputs only. Independent-source streams must retain
exact original forecasts and scores.

Keep static, last-sixteen-distinct-supplied-sources reset, supplied-time/type,
unknown-time and unknown-time/type filters, their exact endpoint laws, uniform
maker prior and complete change hypotheses unchanged. The last-sixteen reset
now retains sixteen presentations when identities are omitted, potentially
fewer true sources. Record both counts. This is part of the declared comparison,
not a pure posterior-temperature manipulation. Supplied source time still
determines each observation's likelihood state; query time determines current
state. Only the known-time/type reference receives the possible midpoint.

Retain full float64 joint weights, hypothesis mappings, forecasts, every score,
source counts, observations and execution-specific timing. Independent review
must reconstruct products and compare each arm against its paired original
identity-aware arm, plus all within-condition arm contrasts. Measures: endpoint
logarithmic loss, current-maker logarithmic loss, true-maker mass, tie-inclusive
90% credible-set inclusion and size. Average sixteen makers within each draw,
then average draws within coefficient lineage. Keep every length, actual change,
reference factor, source condition and checkpoint separate, with both draw means.
Use 10,000 paired lineage resamples, seed 190501, and a 0.02-nat practical margin
for losses only. No coverage margin or universal calibration claim is declared.

Known-answer controls include a counted-twice likelihood ratio, neutral laws,
all-filter independent-stream identity, independently scaled likelihood products,
source-time preservation across changes, conflicting identity rejection, complete
native fixture, parent-score corruption, joint mappings and reader allowlists.
Both full replays and independent numerical reconstruction precede acceptance.

Four CPU hours include failed attempts, tests, run, replays and review, within
B-family and exploration limits. Freeze source, inputs, plan and environment
before outcomes; dispatch through the existing single worker. Public reader
inputs carry only observed context/endpoints, supplied identities and timestamps.
Truth, laws, pairing, forecasts and scores remain in separate scientific exports.
This is a supplied-law constructed-method test, not learned source detection,
historical process correspondence or human intent.

Two independent alternatives remain prepared, requiring their own implementation
and admission: changed-primitive feedback (PRIMITIVE_FEEDBACK_PROTOCOL.md) and
provenance restoration (PROVENANCE_RESTORATION_PROTOCOL.md). Neither requires
an omission effect or a timing win.
