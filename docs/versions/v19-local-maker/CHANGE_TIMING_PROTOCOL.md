Does unknown-time filtering retain its current-state advantage when the actual
change occurs away from the midpoint used in the original comparison? This is
the B-family alternative prepared in SUPPORT_TRANSFER_PROTOCOL.md before the
practice-mixture results. It changes the actual-time distribution, not seeds or
filter capacity.

Use the eight original local-world admission lineages, two original observation
draws, lengths 32/128, purpose/skill complements and independent/copied sources.
Actual changes occur after one quarter or three quarters of each length: 8/24
and 32/96. A source at the boundary belongs to the old state; a new source after
it belongs to the new state. A copy retains its original source time even after
a change. Current-state projection uses query time, not the last source time.
Use exactly the original uniform sequence and context schedule. Freeze every
stream for a lineage before filtering. Protected lineages remain unused.

and unknown-time/type filters. All receive the same exact endpoint likelihood
law and uniform maker prior. The supplied-time/type reference receives the actual
possible time but retains half its prior mass on no change. Unknown-time priors
retain all integer times 8 through length-minus-8, with half their mass on no
change; unknown-type divides the changing half equally between purpose and skill.
Other arms receive no actual timing information. No fit, teacher label, model
setting, hyperparameter search or new observation seed is used.

Keep the existing checkpoints exactly: 8/16/17/20/32 and 16/32/64/65/80/128.
These create unequal time-since-change across actual locations, which is part
of this fixed-checkpoint estimand. Do not pool the two locations or interpret
their difference as an evidence-age-matched effect. Retain endpoint logarithmic
loss, current-maker logarithmic loss, true-maker mass, 90% credible-set inclusion
and set size. The practical margin is 0.02 nats for logarithmic losses only.
Average all 16 initial makers and both draws within each paired lineage.
Keep separate draw means, source conditions, lengths, types and checkpoints.
Use 10,000 paired lineage resamples, seed 190501, in independent review.

published parent scores and means from saved posteriors before new interpretation.
The stationary parent controls and original midpoint cells are retained identities,
not new replicates. Compare every new arm with static, reset and supplied-time/type
where distinct, and each same-arm result with its paired original midpoint.
Retain all original and new denominators. Freeze all comparisons before execution.
