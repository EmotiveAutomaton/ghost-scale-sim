# Regret-aware arithmetic choice: prepared alternative

Would selecting precision for worst regret across a shared arithmetic interpolation
change the original choice, and what objective value would that trade away? Freeze
the same eight laws, 81 assignments, three budgets, four count vertices and three
lengths. No fits, new observations, protected lineages or reader inputs.

Use exact producer/scalar endpoints and the full piecewise-linear partition. For
every feasible assignment, maximize regret against the contemporaneous optimal
assignment over all boundary points. Minimize that maximum; retain all exact ties,
the original computed-float choices, the union and intersection of pointwise optima,
and worst objective value. Keep regret separate from the robust objective itself.
Compare with a choice made using only the producer endpoint and one using only the
scalar endpoint. This is a sensitivity-policy comparison, not a new precision grid
or a certificate of real-valued accuracy. No practical gain is presumed.

Controls: zero-width identity, a known minimax-regret compromise, exact ties,
common affine translation, full-boundary versus endpoint-only failure fixture,
byte charges and nested feasible sets. Require independent reconstruction,
complete-support synthetic timing, frozen source and both full replays within a
prospective inclusive 1,800 CPU-second cap. Prepared, unimplemented and unadmitted.
Realized-risk-constrained channel regret remains the independent alternative.
