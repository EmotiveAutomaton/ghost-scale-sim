# Supplied-law filtering when governing purpose can change

Can a coherent account of one possible purpose change preserve current-state
information better than a static account or a fixed history reset? This advances
the alternative prepared in the routine/revision protocol. It is a supplied-law
ruler for recursive learning, not another trained reader or a local-goal relabeling.

Reuse the complete original three-operation trajectories on admission lineages
190000–190007. Sum native probabilities into endpoint likelihoods for all sixteen
makers and four contexts, retaining every original trajectory as evaluator input.
The full local process and its transient states remain in that retained evidence.
The new observation sequence consists of independent complete native episodes;
its governing purpose can change between episodes, not within a local episode.

Cross all sixteen initial makers equally, two fixed observation draws (190201 and
190202), lengths 32/128, no switch/a single purpose complement after observation
16/64, and independent/duplicated sources. Skill, belief and routine stay fixed.
No model is fitted. Common uniforms pair switch and source conditions. In each
four-slot block the context cycle rotates by one, balancing the omitted contexts
in the duplicate condition. Every fourth slot in that condition copies the prior
source's endpoint, context, source ID and original time. It supplies 24/96 unique
observations rather than 32/128; any difference between these conditions includes
less evidence, not just duplication. Every method counts a source once. Conflicting
content under one source ID is an error. Freeze all streams for a lineage on disk
before comparing its methods. Keep draws within lineage for uncertainty.

Three fixed references receive the same observed evidence and the true endpoint
law: a static uniform-prior filter; recomputation from the last sixteen distinct
sources under that static prior; and a joint mixture assigning equal prior mass
to no switch and the one specified switch time, with a uniform prior over the
sixteen initial makers. The mixture carries complete hypotheses rather than
multiplying separate factor marginals. The possible time is supplied; actual
switch status and maker state are evaluator-only. There is no online detection
claim for an unknown switching schedule. Filtering uses log likelihoods without
probability smoothing. Empty total support is a retained instrument failure.

Evaluate after observations 8/16/17/20/32 for the short stream and
16/32/64/65/80/128 for the long stream. Forecast a fresh endpoint under the current
maker, averaged equally across all four contexts; this is not a forecast across a
future switch. Retain endpoint logarithmic loss, negative log current-state mass,
current-state probability, coverage of a 90% credible set and its size separately.
The credible set includes all states tied at its boundary within 1e-14. Log scores
use a declared 1e-300 numerical reporting floor; raw probabilities remain saved.
Retain every maker/draw/cell posterior, joint hypothesis distribution and forecast.
Later paired intervals use 10,000 lineage resamples, seed 190501, with both draws
averaged within each lineage; the endpoint practical margin is 0.02 nats.

Known-answer controls precede campaign inputs: explicit two-path mixture
enumeration, informative observation, uninformative likelihoods, duplicate identity,
conflicting-source rejection, purpose-complement involution and last-sixteen-source
identity. Isolated tests exercise the full native fixture and the public/evaluator
split. Freeze source, protocol, environment and inputs before admitting original,
adjacent and extracted-source executions to the existing serial queue. Independent
numerical review is required before accepting any comparison. This four-CPU-hour
B-family card includes tests, replay and review; it consumes no tiny setting,
training fit or reserved lineage.

Reader packets contain only observed endpoint sequences, source identity and
context definitions. Maker identity, switch assignment, coefficient lineage,
draw pairing, true laws, posteriors and scores are evaluator material. A correct
fresh-endpoint forecast does not identify the preceding local-goal path.

## Prepared alternatives and limits

The changed-tool support transfer in the routine/revision protocol remains an
independent four-hour F-family alternative, using both saved count fits and common
1/32 final smoothing; it still needs implementation and frozen admission.

A separately prepared B-family discriminator tests the supplied-time privilege:
on the same original lineages and fixed observation draws, compare this frozen
three-reference design with a mixture whose single possible change time is uniform
over steps 8 through length minus 8, plus equal total prior mass on no change.
Cross purpose-only and skill-only changes, keep their observations separate, and
retain current-state scores plus endpoint loss at the same checkpoints. The
skill-switch arm must independently reconstruct its legal-tool support. Allocate
at most four CPU hours, no fit or new seed; freeze its complete design, controls,
source and streams before any outcomes. It is prepared, not implemented or queued.
This isolates a different explanation from changed-tool learned-law transfer.
Neither alternative depends on an advantage here; no confirmation is promoted.
