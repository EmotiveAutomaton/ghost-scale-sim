# An omitted rule inside the legal artifact alphabet

Can an exact reader detect an omitted tool rule when all artifacts remain legal? Artifact and context evidence never empty the old family, although it assigns zero probability to 19.95% and 27.60% of the true joint-process mass. Full operation witnesses expose the omission in 30.39% of the changed-rule population; supplied expansion restores complete process coverage. All 221,184 paths, 57,344 scores and both full replays verify this constructed-method result. Compatible evidence does not certify a complete hypothesis family, and supplying a missing rule is not inventing it.

This is exact inference over a supplied constructed family, with eight original
development coefficient lineages, sixteen makers and four initial/request contexts.
The alternative tool changes presentation alone; the original tool changes the
claim and repairs its evidence. All other mechanics and the goal-before-operation
controller remain fixed, with subsequent choices responding to the changed state.
The full three-step population contains 13,824 paths per rule per lineage. No fit,
new sampling, reserved lineage, or outcome-selected subset enters this result.
