# Retrospective source uncertainty: prepared independent alternative

Does uncertain provenance of a past-state report change the apparent value of
retrospective updating? This unimplemented B-family alternative uses only retained
observations and complete unknown-time/type posteriors, both source conditions,
eight development laws and both observation draws. It is independent of whether
the prior-conditional quotient rival loses to exact conditioning.

For each retained distinct source, use its original time, context and endpoint.
A new report is a copy of that source with fixed probability alpha, or a separately
drawn native emission from the same past maker state otherwise. Freeze alpha at
0, 0.25, 0.5, 0.75 and 1 before outcomes. The resulting likelihood for endpoint e
is alpha times the indicator that e matches the old endpoint, plus (1-alpha)
times the native endpoint likelihood. A copied source is not multiplied into
the posterior twice. Contradictory endpoints at alpha=1 are impossible.

Compare the correctly supplied source-mixture likelihood with always-independent
and always-copy rivals. Enumerate all eight report endpoints under their correct
predictive probabilities, all remaining times and four forecast contexts. Preserve
support failures rather than renormalizing away impossible rival predictions.
Keep source ambiguity, state ambiguity, update error and forecast error separate.
No claim about unknown real-world provenance follows from supplying alpha.

Require all retained row/source identities, fixed-alpha paired contrasts, duplicate
identity and independent-source endpoint controls, impossible-report checks and
deliberately wrong source mappings. Use full lossless factors, both complete replays
and independent numerical reconstruction. Do not regenerate missing checkpoints,
fit a model, add seeds or consume protected lineages. Freeze synthetic full-roster
timing and source before admission. The prospective inclusive cap is 3,600 CPU
seconds within the existing B-family/global ceilings; no sampled substitute or
automatic cap increase is admitted.
