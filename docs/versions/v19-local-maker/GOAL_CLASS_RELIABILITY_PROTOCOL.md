# Complete class-wise goal reliability: prepared alternative

Can confidence in the selected goal hide errors assigned to the unselected goals?
This D-family alternative is prepared and unimplemented. It uses accepted fine-goal
forecasts independently of the modal-confidence calibration outcome. No new fit,
sample, protected lineage or model setting is admitted.

Retain all sixteen development laws, two training draws, five seeds, four budgets,
four readouts, both forecast variants, three step positions and all three goal
classes. Score each class's marginal forecast against its native marginal without
selecting classes by rank or outcome. Use the fixed ten integer-tenth bins,
native and equal-frame weights, complete numerator/denominator sums and explicit
empty bins. Record signed class error, absolute bin discrepancy and expected
multiclass Brier loss, with its native-uncertainty and squared forecast-error
decomposition. Confirm that summing class probabilities preserves normalization;
sum expected one-versus-rest binary Brier terms exactly reproduces multiclass loss.

Compare readouts within each class and matched population; paired lineage bootstrap
seed 191015 with 10,000 draws keeps training draws and seeds inside laws. Preserve
each class and step, alongside equal-class averages. A perfectly calibrated chosen
class with distorted remaining probabilities is a required fixture, as are uniform,
native self-forecast, permuted classes, missing bins and conservation failures.
No recalibration fit, bin search or class selection is allowed.

Complete lossless implementation, isolated controls, all source/input hashes and
conservative timing including two replays and independent review must fit an
inclusive 1,800 CPU-second D card before dispatch. This is a constructed-method
reliability diagnostic; it does not establish historical goals or human intent.
Reader witnesses remain separate from scientific forecasts and evaluator truth.
