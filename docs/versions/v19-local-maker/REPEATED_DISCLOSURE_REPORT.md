# Repeated noisy replies: numerical result verified

We tested whether repeated noisy replies add predictive information when their sources are independent or copied. Four independent 75%-accurate replies reduce forecast loss by 0.01368–0.04472 nats versus one reply across the two fields and tool rules. Copies add no information; treating four copies as independent instead increases loss by 0.02651–0.09358 nats. Independent reconstruction, all 29,952 paired estimates and both complete replays verify this supplied-law constructed-method result; learned access, historical process correspondence and human intent remain unestablished.

The comparison retains 640 queries, eight development laws, original and changed
tools, native and uniform legal-completion conditional laws, and native and
equal-query scoring populations. Skill and belief are requested separately at
reliability 0.75. Zero, one, two and four replies are enumerated completely,
either independent or copies of one noisy return. Readers use the actual channel
or assume independence. No fit, episode or protected lineage is newly consumed.

Correctly conditioned copies reproduce the single-reply forecasts and all
predictive scores exactly. They provide no additional information. Independent
returns improve native-law forecasts; skill gains remain below the declared
0.02-nat reference margin, while belief gains exceed it on both tool rules.
The independence assumption damages copied-reply forecasts for both fields.
No new criterion is used to change an instrument gate.

The primary cost convention charges every returned reply. At a stipulated price

Copies incur the same additional return cost without a predictive gain. The
separate acquisition convention charges copied displays once and preserves
their cost identity with one reply; it does not replace primary return costs.
