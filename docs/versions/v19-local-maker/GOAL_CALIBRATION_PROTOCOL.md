# Goal confidence calibration: prepared independent alternative

Does forecast confidence accurately describe the correctness of local-goal reports?
This independent D-family diagnostic is prepared and unimplemented. It requires
accepted goal-decision forecasts, not a favorable abstention or coarsening result.
No new fitting, samples or protected lineages are admitted.

Retain the complete sixteen-law, two-draw, five-seed, four-budget roster, all four
readouts and both frozen forecasts. For every separate fine-goal modal report,
save its forecast success probability and native expected correctness. Fixed bins
are [0,.1), [.1,.2), ..., [.9,1], with the upper endpoint included only in the last
bin. Numerical values within the inherited normalization tolerance of one are
placed in the last bin without altering the saved probability. Preserve complete
bin numerator/denominator sums, empty bins, both equal-frame and native weighting,
and each of three step positions. No outcome-selected bins or recalibration fit.

Report signed forecast-minus-native success, absolute bin discrepancy, squared
confidence error and binary proper loss. Define zero-probability support and
infinite loss explicitly. Compare readouts at matched budgets and forecasts;
bootstrap paired development laws with seed 191014 and 10,000 resamples, keeping
draws/seeds within laws. Native self-forecast calibration is the oracle control;
uniform, known overconfidence, reversed confidence, empty bins and boundary-bin
fixtures must pass before execution. Fine prediction loss stays an identity check.

This tests calibration of a frozen constructed reader, not historical intentions.
Reader witnesses stay separate from forecasts and evaluator truth. A complete
lossless implementation, isolated controls, source/input freeze and conservative
timing including two replays and independent reconstruction must fit an inclusive
1,800 CPU-second D card before admission. The existing serial queue remains owner.
