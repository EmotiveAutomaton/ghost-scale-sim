# C1: native change/stay fixtures before selective interchange

Can the saved tiny readers support a meaningful test of selective purpose or
belief interchange, including cases where a donor should leave the answer alone?
This first C1 packet audits counterfactual fixtures and saved-model capability.
It trains no model or alignment and does not claim to complete C1 interchange.

Freeze the first 32 original training coefficient lineages and first eight
development lineages, both original history draws, and all sixteen persistent
makers. In each lineage/draw, generate one 32-observation native endpoint stream
per maker. Contexts and all three operation-selection uniforms in each episode
are shared across makers. Each local goal is selected by the existing native
controller before the operation; full trajectories stay in evaluator evidence.
Reuse the two saved architecture settings, two fit seeds and two draws, with
their original weights unchanged. No test or confirmation lineage is consumed.

For each recipient maker, interchange either governing purpose or belief error.
In the change case the donor flips that factor and skill; in the stay case the
donor preserves that factor and flips skill. Skill is a deliberate nuisance: full
donor replacement can change answers even when the selected factor should stay.
The exact hybrid changes only the designated factor, retaining every other
recipient factor. Skill and routine are not local goals, and this is not the
preceding process reconstruction task. Static factor replacements commute by
definition; noncommuting sequential dynamics belong to a later, separate test.

An independent finite-state dynamic program computes all four fresh-episode
endpoint distributions for each maker, including the undo buffer and step. Check
it against complete native trajectory enumeration on every admitted lineage.
Score full endpoint distributions and their total-variation change (half the sum
of absolute probability differences). Stay references must be identical; change
references need not differ in every context. Retain exact effect sizes and any
zero-effect change fixtures instead of filtering pairs using outcomes.

At prefixes 8 and 32, reconstruct every saved transformer and GRU with NumPy
equations. First compare an original saved development forecast and hidden-state
array from every fit against the prior verified capability packet, tolerances
2e-6 for probabilities and 2e-5 for hidden states. Evaluate the new balanced-maker
streams without fitting. Baselines are the unchanged training-target mean, exact
history-conditional prediction, and the known-maker law. Report capability anew
on this challenge; the old pilot's pass does not automatically admit these pairs.

Before any learned alignment, compare recipient decode and full donor-state decode
against the native hybrid law. A donor-state replacement must decode identically
to that donor; this is a computational control, not evidence of selective access.
Its loss on stay pairs measures collateral change. Uncertainty about the maker
means neither reader is guaranteed to match the evaluator's known-maker hybrid.
Keep conditional-prediction error, true-maker uncertainty and intervention effect
separate. No loss threshold will relabel full replacement as selective mediation.

Controls precede science: an informative finite transition, a constant-output
placebo, exact static hybrid change/stay, a skill-nuisance donor, probability
normalization, a known proper score, saved-model reconstruction and deliberate
input corruption rejection. All exact distributions, paired histories, raw
trajectories, hidden states, predictions, component timing and model/input/source
hashes are retained. Reader arrays contain only observable token codes and novelty
flags. Pair labels, factor labels, maker identities and references are evaluator
material; future development alignment supervision must be separately declared.

The existing serial worker executes original, adjacent replay and full extracted
source replay. This packet shares C1's four-CPU-hour cap with its later alignment,
failures and verification. Both tiny settings remain consumed; no Torch fitting,
environment synchronization or sibling modification is needed.

After independently validating this packet, a C1 alignment may use a fixed final
hidden site and rank-one development probe direction, trained only on the frozen
training population, with random equal-rank, shuffled-label, wrong-factor,
mean-direction and full-state controls. Freeze the actual fitting objective and
capacity before execution; this document does not claim that handler exists.

Two independent alternatives remain prepared. F1 uses the existing native local
transition learner to compare direct state decoding, 1/4/16 rollouts and matched
extra decoding at the same query budget, with oracle and wrong-law controls; its
target and teachers must be frozen before fitting. D1's correction extension uses
a bounded supplied family with a probabilistic reliability variable for relation
cues, testing truthful, wrong and explicitly retracted cues against base evidence
and unknown support. Freeze reliability priors 0.5/0.9 and equal cue counts before
execution; do not describe evaluator-selected relation truth as reorganization.
Neither alternative is implemented or admitted by this packet, and neither
requires a selective-interchange win.
