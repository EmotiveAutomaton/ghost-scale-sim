Does pooling public task requests conceal opposing local-goal probability errors?
Derive both groups directly from the legal integer requested-purpose field in each
public packet. Reject nonintegers, illegal values and evaluator fields. Changing
artifacts or witnessed operations while preserving the request must leave group
membership unchanged. A request does not establish adopted purpose.

Reconstruct every group/bin weight, forecast and native-correctness sum using
scalar memberships and accurate summation, independently of producer indexed
accumulation. Preserve binary64 probabilities, ten integer-tenth bins, both groups,
NaN means exactly at zero weight, conditional signed errors, pooled and grouped
absolute discrepancy, and the nonnegative cancellation gap. Check marginalization
over requests against ungrouped sufficient sums. Independently verify base-three
goal marginals before using saved probabilities. Recreate the unsaved native matrix
projection and verify it against scalar sums to retain executed bin assignments;
this does not independently audit the numerical library.

Check all 320 array bundles, 92,160 metric rows, 225,280 frame forecasts, 704 reader
packets and 5,120 parent loss/accuracy identities. Witnessed operations constrain
native support but do not select request groups. Preserve reconstructed arrays
separately from reader inputs. Native self-forecasts must calibrate exactly.

Regroup original and reconstructed rows separately using scalar law means and
bootstrap multiplicities: 576 means, 576 within-readout cancellation estimates,
1,296 paired budget contrasts and 324 normalized log-budget areas. Seed 191018
fixes 10,000 paired resamples of sixteen laws, keeping two draws and five seeds
inside each law. Intervals condition on retained fits. Final numerical acceptance
requires a third direct-index regroup of original rows. No practical threshold
or architecture ranking is added.

Known cancellation and no cancellation, native self, one-group identity, empty
groups, exact/adjacent bin boundaries, permutations, mass conservation, strict
public request membership, artifact/operation invariance, target-field rejection,
full synthetic execution and corruption checks precede source freeze. Synthetic

including failures, tests, original execution, replays and operating work.
Use the existing single-worker queue, CPU only, below normal and one numerical
thread. Original snapshots stay unchanged; no fits, samples or protected lineages.

Execution/replay acceptance remains separate from numerical acceptance. This is
an exploratory constructed-method diagnostic, miniature — architecture untested
beyond the declared roster. Historical purpose adoption and human intent remain
unestablished. Retrospective updating and fixed-bin resolution sensitivity remain
two prepared, unimplemented independent alternatives.
