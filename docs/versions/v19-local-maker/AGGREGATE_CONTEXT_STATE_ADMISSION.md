The implementation retains one future-group mass, 32 joint context/endpoint
masses per group, and 32 integer copy counts. Each joint table includes the
original probability of selecting a source with that context. A context with no
source has exactly zero support. Unknown source identity remains marginalized.
Endpoint-only state is obtained by summing context masses before normalization.

The full-hypothesis reference independently weights every source's report
likelihood. Compare all 32 context/endpoint outcomes, all five copying
probabilities and every future time, context and endpoint. Report exact support,
undefined errors, forecast discrepancy, group total variation and the expected
squared-loss cost of retaining only endpoints. This last quantity weights the
context-specific forecast distance by the full joint report probability; explicit
one-hot loss fixtures check that interpretation. It is predictive information,
not recovery of the historical source or maker process.

The source-frozen design keeps all 28,672 saved posteriors, 505,856 source
candidates, eight laws, two evidence conditions, two paired draws and seven
available structures. It produces 143,360 summary rows and 4,587,520 report
queries. The 48 unavailable checkpoint strata remain absent. No new observation,
fit or protected lineage is used. Shared 512-value law information and all future
schedules remain separately counted; full hypothesis weights and full schedules
are separate reference costs. No minimum-storage or optimized-latency claim.

Admission requires isolated scalar Bayes and proper-loss controls, source/context/
endpoint permutations, missing-context support and corruption of state, counts,
masks and storage. Complete-support synthetic timing must include all seven
structures, both source densities, serialization, three complete executions,
independent reconstruction and separate original-row regroup within the inclusive
3,600 CPU-second card and existing family/global ceilings. Until those receipts
exist, implementation is not scientific admission. Numerical acceptance later
requires both complete replays and independent reconstruction.

Highest-probability retention and a fixed bank of source-prior tables remain
prepared independent alternatives. This experiment tests one fixed source/report
law with disclosed context; arbitrary source-prior changes, source disclosure and
dependent report pairs remain separate questions.
