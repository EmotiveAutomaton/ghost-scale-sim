# Learning the source of a past report: prepared independent alternative

Does revealing which old source a report concerns improve future predictions
after its content is already known? Use the same retained posteriors and every
true distinct source, uniformly selected before report emission, and the five
fixed copying probabilities. Compare exact posterior forecasting from report
content alone with exact conditioning on both content and source identity.

Enumerate every source and endpoint; retain their joint probability and separate
impossible pairs. Measure expected future-probability squared-loss reduction,
source entropy reduction and future-schedule total variation. A variance identity
must independently equate expected squared forecast change with expected proper
score improvement. All future times and contexts are included; source disclosure
cost is one categorical answer with its alphabet size recorded. This is a
supplied-law value-of-information calculation, not learned provenance or an
observed process correspondence result. Even if uniform source averaging ties
exact marginalized inference, source disclosure can remain informative.

No implementation or execution is claimed. Require constant-law, single-source,
identical-source-likelihood and heterogeneous-source controls; scalar direct
conditioning; complete identity/multiplicity preservation; full-support synthetic
timing and source admission. Prospective inclusive cap 3,600 CPU seconds inside
existing B/global limits, including both replays and independent reconstruction.
Do not fit, sample source identities, regenerate missing checkpoints or consume
protected lineages. Two-report dependence is the other prepared alternative.
