# Bounded retrospective forgetting: prepared independent alternative

Does a compact recent-source window preserve useful updates when a later report
can refer to any earlier source? This unimplemented B-family alternative keeps
the retained complete posteriors, eight laws, two evidence conditions, two draws
and every source identity. It creates no new observations or fit.

The correct oracle integrates all original sources under the uniform prior.
Compare fixed last-quarter and last-half source windows, selected by original
time before outcomes, with an explicit unknown-source remainder. The remainder
retains only its probability mass and original endpoint histogram; its independent
report likelihood uses the pre-history maker prior rather than retained joint
past-state information. Preserve the full source mass; do not renormalize the
recent sources as if older evidence never existed. Full retention is an identity
control and complete forgetting is a declared comparator.

Enumerate all eight endpoints and five existing copy probabilities. Measure exact
support failure, expected future squared-loss regret and worst future probability
error separately, with float and integer storage costs. Compare recomputation
with the bounded state; no favorable accuracy is required for a useful cost result.
Require direct scalar Bayes, constant-law and full-retention identities, an older
informative-source positive, source-permutation invariance with preserved times,
and omitted-mass corruption controls.

Prepared only: complete-support timing, implementation, controls and frozen
admission are required. Prospective inclusive cap is 3,600 CPU seconds within
the B-family and global limits, including failures, both complete replays and
independent reconstruction. No source sampling, protected lineage or new fit.
Two-report dependence remains a separate prepared alternative.
