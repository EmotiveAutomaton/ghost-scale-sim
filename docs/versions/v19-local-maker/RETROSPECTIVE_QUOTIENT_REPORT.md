# Retrospective quotient: independent numerical acceptance

We tested whether preserving future forecasts also preserves updates from a new report about the past. It does not over the declared possible mixtures: all eight laws contain witnesses, with a largest future probability change of 0.25898. Independent reconstruction, all 80 regrouped rows and both complete replays verify this constructed-method result. Reachable-posterior effects, historical process correspondence and human intent remain unestablished.

A future-schedule group combines hypotheses with identical maker states from
the checkpoint onward. For every within-group pair with different past schedules,
the certificate compares two mixtures: half on one pair member and half on the
same third hypothesis outside that group. It enumerates all earlier report times,
four contexts, eight endpoints and all remaining-time forecast coordinates.
Reports are separately sourced emissions. A known-source copy adds no evidence.

The eight development laws yield 781,545,234,432 logical report
comparisons. Both mixtures permit 765,110,075,904; neither permits
7,377,464,832; exactly one permits 9,057,693,696.
There are 366,036,967,424 valid update and forecast witnesses
above the prespecified absolute tolerance of 1e-12. Binary64-nonzero counts agree
here, but this is not exact rational arithmetic. The largest total variation
between the updated two-group distributions is 0.79898425;
total variation is half the summed absolute probability difference. The largest
change in a future endpoint probability is 0.25897621.
