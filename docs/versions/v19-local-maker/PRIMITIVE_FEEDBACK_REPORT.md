# Fixed primitive feedback: execution complete

We tested whether observed tool transitions can repair a frozen forward model without harming unchanged queries. The fixed feedback comparison completed 640 queries and 1,966,080 paired score rows with no new fits. Execution integrity passes; independent numerical and replay acceptance remain pending. No predictive advantage or process-correspondence claim is accepted yet.

Two saved count draws and original/composition-holdout training modes retain all
640 queries and eight original evaluation lineages. Original and changed tools
are crossed with forward/reverse input order, truthful/bit-flipped feedback,
0/4/16/64 unique input budgets, and unchanged/add-one/row-replacement updates.
The 384 updated-table/forecast comparisons yield 245,760 forecast vectors,
1,966,080 paired score rows and 92,160 aggregate cells. Repeated deterministic
input reports count once; distinct inputs are not independent sampled trials.

The saved unit prior is retained once in the additive arm. Row replacement
changes only observed rows. All forecasts use the same final 1/32 smoothing;
no new fitting, architecture setting or protected lineage is consumed. Scores
retain native query weights and equal-query weights separately, plus changed/
stay and original support strata. Supplied skill, belief and operation metadata
remain explicit teacher privileges. This is not unobserved-row interpolation.

Original integrity verifies 508 source files, 33 frozen inputs and all 831
deterministic outputs. Ten internal controls pass, including zero-feedback
identity, one prior, deduplication, balanced unique inputs, wrong feedback and
an independent sum over all 512 intermediate paths for each forecast. Original
summary, model tables, forecasts, proper scores and every denominator are
retained in scientific archives. Internal identities alone do not accept a
numerical outcome; the adjacent and extracted-source replays have later events.

The new independent checker rebuilds feedback with the previously validated
independent executor, implements updates separately, and reuses that reviewer's
explicit path sum. It checks every forecast and proper score, reconstructs
native masses from retained paths, checks support labels and each anonymous
reader slice, and regroups both saved fits inside paired lineages. Parent fit
and native path-probability validation is inherited and explicitly bounded.
Nine isolated controls pass, including a complete native fixture, deliberate
table/forecast/loss/population corruption and bad denominators, plus runtime and
portable dispatch. The initial fixture attempt failed because its intentional
corruption tried to overwrite an immutable fixture record; the retained repair
permits mutation only in those temporary corruption fixtures. No scientific
criterion or result was changed. Source admission and serial execution follow.
