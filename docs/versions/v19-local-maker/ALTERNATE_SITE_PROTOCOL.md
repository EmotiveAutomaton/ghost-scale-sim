# C1: one alternative transformer site

Can selective factor access improve when the same intervention is applied before
the transformer's final normalization? The original ridge direction changed
predictions by less than the declared practical margin; its class-mean belief
control damaged stay cases. This is the one alternative-site attempt allowed by
the opening C1 branch. It changes neither sequence weights nor the prediction head.

Use the exact original fixture population: 32 training and eight development
coefficient lineages, all sixteen makers, two training draws and two saved seeds.
Only the four saved transformer fits enter this site comparison. The recurrent
reader has no corresponding final normalization; no matched recurrent site is
claimed. Keep all donor/hybrid pairs, skill nuisance changes, factor labels,
prefixes 8 and 32, random control seeds and native targets unchanged. No test or
confirmation lineage is consumed and no new sequence-model setting is attempted.

Reconstruct the final token state after the feedforward residual addition but
before the second normalization. Verify that applying the unchanged normalization
recovers every saved final state and prediction to absolute tolerance 1e-12.
This identity gate precedes the auxiliary probe fits for each saved model. The
normalization uses the original learned scale and bias, population coordinate
variance and fixed epsilon 1e-5. Apply it after every unchanged, rank-one or full
state substitution, followed by the unchanged head. Never bypass normalization
to make the new direction look useful. Preserve reconstructed training and
development states and all resulting forecasts.

Probe architecture and supervision are fixed: one unit direction in 32 dimensions
for each of governing purpose and belief, signed balanced training labels, and a
centered ridge solve at prefix 32. The penalty is 0.001 times the mean covariance
diagonal plus 1e-8, exactly as in the original access experiment. There is no
optimizer schedule, grid, development selection or intervention-outcome training.
Compare unchanged, learned, random equal rank, within-lineage shuffled labels,
wrong factor, training class-mean direction and full-state replacement. Directions
use the same fit/factor random seeds. Prefix 8 is transfer, not an additional fit.

Retain every original logarithmic loss, oracle entropy, target total variation,
prediction movement and decodability measure. Main contrasts are each arm minus
unchanged, learned minus each control, and the paired new-site minus old-site
change/stay loss differences. Pair within all eight coefficient lineages, average
makers/draws/seeds inside lineage, then use 10,000 resamples with seed 190501.
Report per-fit variation separately. A practical selective candidate must improve
change predictions by the existing 0.02-nat margin while keeping stay damage
below that margin for the same factor and relevant controls. Do not combine a
safe purpose result with a damaging belief result into joint mediation. A second
site attempt does not authorize an unbounded site search or C2 composition.

Before dispatch, test normalization's common-shift identity, a live coordinate
effect, constant-output placebo, original-output and duplicate identities, causal
prefixes, all seven normalized substitution arms in a complete synthetic fixture,
wrong-site rejection and corrupt saved-state rejection. Use isolated verification,
the existing serial queue and both full source-bound replays. Charge fitting,
reconstruction, verification and failures to the original C1 four-CPU-hour cap
and the shared V19 exploration pool. The nonlinear models remain frozen; only
explicitly privileged auxiliary linear probes are fitted.

Blind reader inputs remain anonymous observation codes and novelty flags. Factor
labels and directions belong in auxiliary training; native laws, pair mappings,
saved hidden states and scores belong in evaluator/reproduction evidence. Source,
plan, input and environment hashes are frozen before any new probe outcome.

Its paired comparison is direct endpoint counts, 1/4/16 learned continuations,
matched direct aggregation, oracle continuation and a fixed wrong-law control;

It is not implemented or admitted here. A D-family missing-cause fixture will
introduce a tool rule that toggles the presentation bit while leaving claim and
evidence unchanged, whose outputs remain inside the three-bit artifact alphabet.
Use the same four initial/request contexts, sixteen makers and eight development
lineages, with exact enumeration rather than new sampled seeds. Compare old-family compatibility with and
without witnessed operations, a supplied expanded family and abstention. Freeze
the changed rule and paired contexts before outcomes. This tests detection and
supplied candidate expansion, not open-ended cause invention; it is prepared
only, with a separate finite manifest required before execution. Neither branch
depends on a selective-access win. The broader primary and research week remain
