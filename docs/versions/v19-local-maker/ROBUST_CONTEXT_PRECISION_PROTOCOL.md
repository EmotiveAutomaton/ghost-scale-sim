# Unknown query composition: prepared finite alternative

Can a precision allocation remain useful when query composition is uncertain?
The balanced-schedule allocation knows how often each context will occur.
This alternative freezes an uncertainty set before outcomes: the convex hull
of four count vectors that put 13 of every 16 observations on one context and
one on each other context. The balanced schedule is their equal mixture.
Use lengths 16, 64 and 128, the same eight retained laws and all 81 assignments
of half/single/double precision to four contexts, at the same 1,280/1,536/2,048
byte budgets. No new histories, fits, tiny settings or protected lineages.

For each assignment, the maximum accumulated log-ratio range over this convex
set occurs at one of the four vertices. Enumerate those vertices and select
all assignments minimizing that worst-case range under each budget. Compare
the balanced-schedule choice, uniform feasible precision and the best separate
choice at each vertex. Preserve all choices, ties, exact byte counts and each
vertex's regret. Tie order is float16,float32,float64 by context. This is finite
robust bound allocation, not realized posterior error or general compression.

Controls: independent scalar exhaustive minimax, fixed rational mixtures of
all vertices, equal-context and exact-cast identities, a balanced optimum that
is a poor robust choice, matched context permutations, infeasible budgets,
support loss and deliberately undercharged bytes. Teacher access is the
supplied evaluator law; no evaluator fields enter reader inputs. Require full
support synthetic timing, frozen source, original and two full replays,
independent reconstruction and original-row regroup before any acceptance.

Prepared, unimplemented and unadmitted. Its prospective separate inclusive
cap is 1,800 CPU seconds within the existing family and global limits. This
does not extend another card's cap. Robust source-prior mass retention is the
other independent prepared alternative. Learned access, historical process
correspondence and human intent remain outside the claim.
