# Independent retrospective source-mixture review

Do the saved source-mixture likelihoods and future discrepancies reproduce from
the retained hypotheses and observations? This checker imports no producer
kernels. It uses the independently validated bit-state/schedule constructor,
indexes past-state masses, and uses scalar sums for all eight report probabilities.
Direct hypothesis Bayes updates determine independent-minus-copy weights.
Indexed accumulations at each actual state change and prefix sums reconstruct
every remaining-time, four-context, eight-endpoint forecast difference. Tests
compare this method to direct enumeration at every time and endpoint.

For all five frozen copying probabilities, reconstruct every scalar report
denominator, copy fraction and possible/impossible flag. Analytically cancelled
weighted errors supply an independent reconstruction of support failure mass,
supported error mass and maximum supported error. Source means are taken inside
each posterior before law/source/checkpoint/draw/alpha strata. Conditional error
is a pooled error mass divided by supported mass, undefined for zero support;
it must not be an average of conditional source errors.

Reconstruct all true distinct source identities, including original step,
context and endpoint, in both posterior evidence conditions. Copies add no
second source. The native streams and parent forecasts must reproduce; source
metadata is supplied for designing reports, not learned by either reader.
Retain every raw factor, parent binding and missing checkpoint. Freeze 1e-12
absolute numerical tolerance before reconstruction; exact support flags are
checked separately. Do not clip, round, tune or regenerate scientific evidence.

Known-answer controls cover constant, sparse and disjoint laws, zero posterior
mass, copies and independent sources, impossible reports, stationary and changing
states, every future coordinate and deliberate data corruption. Complete
synthetic producer/checker integration must pass in an isolated source copy.
Measure full-support synthetic reconstruction before admission within the
unchanged inclusive 3,600 CPU-second card and family/global limits. Charge tests,
failures, independent review, final regroup and publication-related work.

Execution and both complete replays are evidence for reproduction, not numerical
acceptance. The serial checker emits a separate completion event; that reviewer
must regroup original raw rows independently, preserving both draws within eight
paired laws and all source/checkpoint/alpha strata, before accepting quantities.
This supplied-law constructed-method comparison does not establish learned
provenance, historical process correspondence or human intent. Two-report
dependence and bounded provenance intervals remain prepared independent designs.
