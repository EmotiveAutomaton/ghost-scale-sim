remain supported? Use the same retained posteriors, true source identities and
complete report alphabets. Freeze intervals [0,1], [0.25,0.75], [0,0.5] and [0.5,1].
Compare the complete posterior/forecast envelope with fixed midpoint and endpoint
reports. For the original endpoint, the posterior is a monotone scalar mixture
between copied and independent updates, permitting exact endpoint envelopes for
each forecast coordinate. For differing endpoints every permitted positive-mass
update is independent; an interval containing only alpha=1 is impossible.

Keep unsupported reports, coordinate envelope width and simultaneous posterior
compatibility separate. An interval is supplied uncertainty, not an inferred or
calibrated real-world provenance probability. Enumerate all retained source and
future identities and require direct interior-alpha controls, constant and
disjoint laws, endpoint inclusion and deliberately invalid intervals.
