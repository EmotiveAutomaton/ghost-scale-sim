# Earlier and later actual changes: replay verified, numerical review pending

Does a filter retain useful current-state information when actual changes occur earlier or later? The comparison and both complete replays agree on 77 deterministic outputs across 4,096 streams and 112,640 scored rows. Independent reconstruction is source-frozen; numerical advantages remain unadjudicated. This is a constructed-method reproducibility result with supplied laws, not historical process correspondence or human intent.

The actual purpose or skill change occurs after one quarter or three quarters of
the stream: after observations 8/24 for length 32 and 32/96 for length 128. Every
other scientific choice remains frozen from the original midpoint comparison.
Static filtering, a last-sixteen-distinct-source reset, supplied-time/type,
unknown-time and unknown-time/type filters share the true endpoint likelihood law
and a uniform maker prior. Only the supplied-time/type reference receives the
actual possible time. It still retains half its prior mass on no change.

sixteen equally weighted initial makers and two original observation draws.

and 7,040 maker-averaged strata. It introduces no new fit, model setting, seed or
protected lineage. Original midpoint and stationary streams and scores are
reconstructed identities, never additional replicates.

belong to the changed state. Copies retain original source identity and time.

24/96 distinct sources compared with 32/128 independent sources, so their
