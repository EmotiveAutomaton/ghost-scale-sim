# Independent verification of the bounded optimizer comparison

The optimizer experiment is complete; its scientific conclusion remains pending
independent numerical reconstruction and complete replay comparison. Verification
uses the existing scientific queue and the original card's four-hour cap. It fits
no model, samples no new world and consumes no tiny-model setting.

The verifier freezes the completed experiment's plan, completion receipt, every
deterministic output, execution timing and all retained numerical inputs. It also
pins the predecessor's optimization record. Before reading these outcomes it
checks a known binary logarithmic loss and gradient, a constant-label placebo,
finite-difference derivatives and probability normalization. Admission checks
source syntax and the input closure; numerical controls execute inside the sole
scientific worker. This is not a claim that the amended source has already passed
the previous 38-test numerical suite.

Independent code reconstructs representations, forecasts, nested-label means,
exact references, every scored row, each final objective and both gradient norms.
It uses log-add-exp normalization and does not import the producer's objective,
gradient, scoring or fitting functions. It checks returned solver status against
actual maximum absolute gradient, preserving iteration-limit terminations.

Paired areas retain eight old-world or sixteen local development lineages, both
feature seeds and both training draws within lineage. All four old classes and
their equal-weight population are retained. Local goal and operation curves are
separate. Source-bound replay comparison remains a separate requirement: the
operator must compare all deterministic output hashes from the original,
adjacent replay and fresh extracted-source replay before accepting the batch.

The original unfloored softmax scoring is unchanged. Reconstructed scores can
establish what these fitted models did; small gradients alone cannot establish a
universal access limit, process correspondence or human intent.
