# In-alphabet omitted tool rule

Can an exact reader detect an omitted cause when every artifact still uses legal
renderings? The earlier outside-family fixture used an illegal symbol. This
independent D-family continuation changes only `accept-tool`: the alternative
rule toggles presentation and leaves claim and evidence unchanged. Skill still
controls tool availability. Controller choices, local goals selected before
operations, undo buffers, contexts and all other execution rules are unchanged.
Subsequent choices use the changed artifact. This is a supplied-law constructed
method experiment, not open-ended invention of a cause.

Freeze eight original development coefficient lineages 190000 through 190007,
all sixteen makers, four original initial/request contexts and all three-step
trajectories under each rule. There are 13,824 paths per rule per lineage.
No sampled outcomes, new seed blocks, fitted models, test or confirmation lineages
are used. Each rule population has its own normalized natural trajectory weights;
report original and changed populations separately, then their equal-weight mixture.

Compare final artifact alone, initial/request context added, first operation
witnessed and every operation witnessed, using the original public projection.
No hidden goal, rule identity, lineage or truth-selected case label enters a
reader packet. Anonymous hashes deduplicate identical evidence. Full raw native
paths, including transient states and goals, remain evaluator evidence.

Four readers are fixed before outcomes: exact original-family conditioning;
exact expanded-family conditioning with equal prior mass for each rule; uniform
compatible templates from that same expanded family; and exact known-rule
conditioning as a privileged ceiling. Expanded-family readers are supplied the
alternative semantics. They do not discover it. The uniform template baseline
counts complete paths equally and is not a calibrated probability model.

For every unique public packet and true rule, preserve its natural probability
mass, full true goal/operation distribution and each reader's distribution. A
process identity includes all three local goals and operations. Score exact
candidate coverage, positive-mass unsupported true process probability, abstention
when the reader has no compatible path, posterior entropy, compatible hypothesis
count, and expected joint goal/operation logarithmic loss. Never floor zero
probability: report the natural mass producing infinite loss and the finite
contribution separately. Abstention is not scored as a successful prediction.
Expanded readers also report posterior probability of the actual rule; that
evaluator score is distinct from process recovery. Detection means empty original
support, not merely a small posterior or a correct expansion result.

Aggregate within true rule, tier and lineage using native probability mass, then
average the eight lineages. Any intervals resample paired coefficient lineages
10,000 times with seed 190501, conditional on this finite architecture. Preserve
all per-lineage values. No modal winner or arbitrary tie-breaking is a primary
measure. The practical question is which evidence exposes the omission, which
continues to admit a wrong family, and how much supplied expansion repairs coverage.

Before dispatch, require known-answer tests: both tool transitions; identical
non-tool operations; unavailable low-skill tool; all-inspect cross-rule identity;
full witnessed changed-tool incompatibility with the old rule; normalized path
mass; original enumerator equivalence; exact and uniform posterior controls;
zero-support abstention; zero-mass/infinite-score handling; and a complete isolated
fixture with role-separated outputs. Bind source, plan and environment before
outcomes. Use the existing single worker and both full replays. Initial cap is
two CPU hours, charged within the eight-hour initial D-family allocation and
shared exploration pool; all failures and verification count.
