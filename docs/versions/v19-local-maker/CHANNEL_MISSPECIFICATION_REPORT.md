# Misjudged cue reliability and storage - 25 September 2026

We tested whether misjudging cue reliability can harm storage when the source mixture is correct. When an uninformative cue is treated as two-thirds correct, cue-guided storage performs worse than ignoring it in 147 of 420 distinct problems. Independent rational reconstruction and both full replays verify this constructed-method reversal; it does not establish forecast accuracy or process correspondence.

Retained coverage is the probability mass of source records kept by a storage
mask. The source-prior mixture stays correct throughout this experiment. We
choose each three-label contingent storage policy using the assumed cue channel,
freeze it, and score it under the actual channel. The 28 finite mask libraries
cross 15 quarter-grid mixtures and three assumed by three actual cue reliabilities,
giving 3,780 distinct structural problems. These are not independent sampled worlds.

With an uninformative actual cue, assuming two-thirds correctness harms coverage
in 147 of 420 problems; assuming perfect correctness harms it in 280. When the
actual cue is two-thirds correct but assumed perfect, 162 problems lose to fixed
storage and 118 improve. Thus both the direction and cost of miscalibration depend
on the source mixture and feasible storage library. All 1,260 matched-channel
problems have zero regret relative to optimal actual-channel cue use.

Assuming an uninformative cue gives the fixed-storage result under every actual
channel. It forgoes a possible benefit in 147 problems with two-thirds-correct
cues and 174 with perfect cues. Perfect-channel assumptions give positive actual
probability to nominally impossible labels in 336 problems for each imperfect
actual channel. Those labels retain the predeclared largest-mask tie rule.
