# Independent provenance-restoration review

Reconstruct every native endpoint law, saved stream, correction pair and nested
correction condition without importing the producer's correction, filtering or
scoring code. Reuse the independently implemented scaled-product checker. Check
every hypothesis/prior, source-time likelihood and current-time state projection,
joint array/index, current-maker posterior, forecast, type mass and all five
scores. Reconstruct reset selection after each correction and count retained true
sources. Zero/full/label-only identities are controls, not empirical benefits.

Preserve all eight lineages, two draws, sixteen equally weighted makers, lengths,
reference factors, actual change states, source conditions and checkpoints. Average
makers within draw, then draws within paired lineage. For each unique correction
condition compare against zero and full correction. Separately compare ascending
and descending evidence age at each declared budget; retain clipped-budget aliases
without counting them as independent observations. Report five measures, draw
means, paired lineage values and 10,000 percentile bootstrap replicates with seed
190501. The 0.02-nat practical margin applies to losses only. Stationary reference
factor copies remain paired identities, never extra evidence.

The native serial worker must first pass the frozen checker tests, including a
complete native fixture, independent scalar products, crossing-time copies,
reset-history reconstruction, zero/full/rename identities, alias pairing and
corruption/reader-truth rejection. It then reconstructs the completed campaign
result in the same job. This gate is pending at admission; syntax checks do not
claim numerical validation. No second scientific worker or model fit is needed.
The four-hour restoration cap includes this verification and the two replays.

Reader exports contain observations, timestamps and explicitly supplied source
equivalences only. Native truth, laws, full arrays, scores, uncertainty estimates,
and checker products have a separate evaluator/reproduction role. Complete replays
and independent numerical acceptance are separate receipts. Bounded primitive
feedback and retained filter-cost accounting remain independent prepared designs.
