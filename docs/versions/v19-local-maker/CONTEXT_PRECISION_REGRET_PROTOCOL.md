# Query uncertainty: prepared minimax regret alternative

Does minimizing absolute worst-case rounding error choose differently from
minimizing loss relative to a query-informed allocation? Freeze the same eight
laws, 81 precision assignments, three byte budgets and four count vertices
(13,1,1,1) at lengths 16,64,128. No new histories, fits or protected lineages.

For each feasible assignment and vertex, subtract that vertex's best feasible
accumulated log-range. Minimize the largest such regret; retain all ties and
compare the absolute-bound minimax choice, balanced choice and vertex-specific
optima. Regret is in log-range units before tanh, not in realized posterior loss.
For any convex mixture of vertices, fixed-assignment regret is the maximum of
linear contrasts against competing feasible assignments and is convex. Its
maximum over this hull therefore occurs at a vertex. This does not justify
using vertex regrets for an arbitrary nonlinear regret estimand.

Retain complete arrays, exact integer byte charges, all choices and regret
denominators. Controls include independent exhaustive scalar reconstruction,
fixed rational mixtures, a case where absolute minimax differs from regret
minimax, zero-regret identities, context permutations, infeasible budgets and
infinite-minus-infinite undefined values. Record computed-float tie sensitivity.

Prepared, unimplemented and unadmitted. Teacher access is the supplied evaluator
law; no new reader input is created. Require frozen sources and complete-support
timing, original and two full replays, independent regroup and full write-through
within a separate inclusive 1,800 CPU-second cap. This addresses an allocation
criterion, not learned access, historical process correspondence or human intent.
