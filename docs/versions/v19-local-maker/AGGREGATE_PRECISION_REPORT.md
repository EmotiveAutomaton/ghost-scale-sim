# Finite-precision aggregate state: engineering disposition

The finite-precision aggregate-state prototype passed 60 isolated controls, but complete-support timing after one storage repair projects 6,007.00 CPU seconds against its 3,600-second cap. No native scientific job was admitted; this is an engineering blocker, not a scientific null.

The question is whether an otherwise sufficient report state remains usable when
stored with fewer bytes, especially for low-probability reports. Float64, float32
and float16 storage and both direct and mass-preserving reconstruction are fixed.
The implementation uses float64 query arithmetic and integer copy counts, retains
underflow and drift before repair, and separates unsupported forecasts from
defined errors. This is an implementation result; no scientific precision effect
has been measured on the native population.

Both initial and repaired snapshots pass 60 isolated controls, including 17 new
precision controls and the retained aggregate/runtime/portable-dispatch checks.
Scalar source-level Bayes, every future coordinate, explicit one-hot proper loss,
constant and certain-copy cases, rare-report support loss, positive empty joint
rows, actual stored dtypes, permutations, corruption and complete synthetic
integration are covered. These controls do not establish native performance.

Full-support synthetic timing includes all seven structural checkpoints, both
source densities, regular/random/single-context schedules and three complete
32-row serialized batches per shape. The initial inclusive estimate was
10,701.02 CPU seconds. Removing only exact
and deterministically recoverable raw-array duplicates lowered it to
5,976.00, before charging the repaired
benchmark itself. The final admission estimate is 6,007.00 seconds.
The three complete executions alone project 3,492.00
seconds; independent reconstruction reserves 1,946.00,
original-row regroup 250 and operations 200. All prior checks and both benchmark
charges are retained. No scientific roster was sampled or reduced.

Both source archives, both control logs and every timing measurement remain.
No native plan or job was admitted. No further repair with a supported path below
the inclusive cap is identified this turn; this does not prove none exists.
Highest-probability source retention and shared endpoint-law precision are two
prepared, unimplemented alternatives. The accepted aggregate-state finding and
89 scientific batches remain unchanged. Learned access, historical process
correspondence and human intent remain unestablished.
