# G1b frozen primary protocol
Ninety settings, each eight independently drawn libraries with 25 worlds, for 200 worlds. Shared uniforms pair contexts; histories are nested across K. The current page is included in own-history estimates as in V28. Pe-A uses K context-A histories; Pe-B uses K context-B histories; both score a context-B page. The typical reader uses the mean true context-B library habit, matching V28's privilege. MIX weights Pe-A by K/(K+4). The independent scalar reconstruction computes all probabilities and scores separately. An omega-one retained-path check reproduces eighteen published V28 Pe means within 1e-10 without resimulating V28. Sampling intervals are over eight library blocks; worlds within one library are not independent units. There is no logistic slope, tremble or time-to-separation outcome in this family, so those texture knobs are inapplicable. The open map is context-transfer degradation and whether shrinkage dominates both alternatives. No claim about real writers follows.
