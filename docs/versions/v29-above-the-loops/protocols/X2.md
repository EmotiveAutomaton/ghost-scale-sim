# X2 frozen primary protocol
The primary has 144 freeze settings and 24 post-breach settings. Freeze lives run 2048 steps, with a 1024-step visible window starting at 0, 256 or 1024; post-breach records use the full 2048-step life. Each cell has 200 worlds in eight blocks. Reader grids and shared equations follow the packet. Late entry uses a uniform prior over streaks zero through n-1 plus an already-frozen state for each FROZE model; it does not use the true prehistory law or evaluator state. Other model states initialize at entry. Initial-entry readers begin live. Class evidence averages base members after marginalizing their declared state prior, with equal class prior. The excluded pilot drops cells below 20% freezing incidence, explicitly a design exclusion rather than universal LIVE behavior. Overall and pairwise sustained separation retain censoring. Freeze dating uses the first posterior probability at least .5 conditional on FROZE, and dating error is reported only for freezes inside the observed window that received a date; coverage and pre-entry censoring are separate. Post-breach records report resolved-only elapsed time, unresolved share conditional on breach, available follow-up and event counts; a missing breach is never a zero delay. Controls include late-entry mixtures and both breach rules. All twenty applicable original preflight paths match. The initial empty-set reference failure and its one allowed repair remain retained; no further automatic X2 repair is admitted. Scalar probabilities and state transitions independently reconstruct the whole map; shared summaries and generators are a limitation. Miniature, no registered claim.
