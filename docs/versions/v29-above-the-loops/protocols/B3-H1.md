# B3-H1: retained-data interval repair
Before publishing the B3 primary, review found that B3b's fitted loading matrix shares training observations across all eight blocks. Treating its resulting per-block scores as independent does not represent that fitted dependence. The original points, intervals, numerical verification and raw paths remain intact. The per-agent B3 primary does not share fitted parameters and is unaffected.

This is B3's one allowed healing attempt, using retained data only. First reproduce every affected original point estimate within 1e-10. Then draw 4000 independent resamples of the eight whole blocks, keeping each agent's training and held-out observations paired. Refit the two-readout and three-readout models inside every resample and take the 2.5th/97.5th percentile interval. Repeat separately at all six declared training prefixes. Correct the first-positive-interval readout from those intervals. This does not upgrade the descriptive curve to a multiplicity-corrected claim.

The source is frozen before execution. One original computation, a fresh-process byte replay, and an independent count/covariance/eigendecomposition reconstruction are required. The latter must reproduce every stored bootstrap statistic and final summary within 1e-8. Controls include known rank-one equality, a constant law, batched versus individual refits, and independent predictive scores. Each pass has a 900-CPU-second cap, charged to the existing protected reserve, with no new worlds, model changes, altered sampling plan or extended deadline. Any failure is retained and stops this repair; no second automatic B3 healing is admitted.
