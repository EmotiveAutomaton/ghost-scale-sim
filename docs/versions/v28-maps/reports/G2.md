# G2: visible-stock planning map

Which set-point rules can a visible record distinguish, and how much record is needed? Across the 28-cell planning map, the one-sided defender remains unresolved against the dulling type in 63.75% of ordinary 256-step paths. A prolonged deficit separates them at a median statistic of 86 (95% interval 84–91), with 0.25% unresolved. Extending the ordinary record to 1,024 steps also separates them: median 817.5 (694–917), with 34% unresolved. The apparent alias is therefore horizon-dependent, not an exact equivalence of these positive-rate models. This is a descriptive constructed-method scale map, not evidence about people.

Implementation choices: the single 1,024-step ordinary cell is ONE(12,1), frozen before outcomes. Moving references use the previous pre-action stock; counters include the current stock. Stock updates follow action, disturbance, windfall and clipping.

There are 28 settings, 400 independent worlds each, 27 at 256 steps and one at 1,024. Every row is scale only. Exact type evidence integrates each parameter grid with equal type priors. A separately written scalar kernel reconstructs the complete grid.

A spend rules out no-spend types. Identical conditional action laws give zero conditional evidence increments; differently learned parameter distributions can still give different marginal increments. Exogenous disturbances carry no type evidence. Positive 0.02 rates create near-aliases over short records, not exact infinite-history aliases.

The separation statistic is literally one plus the last zero-based step below one nat. It is not the first crossing. Zero means above the bar after the first observation; a final below-bar path is right-censored. Median intervals preserve censoring. Fitted-model losses are in-sample comparisons, so a fitted correct-class model can slightly outperform its true parameter on that same sample. Means use world-level t intervals, proportions Wilson intervals, and medians binomial order-statistic intervals. All are pointwise descriptive.
