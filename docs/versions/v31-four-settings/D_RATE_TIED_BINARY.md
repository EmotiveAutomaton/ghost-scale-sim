# D: Event rate tied to sensitivity, binary events

How do diary estimates behave when event rates are tied to sensitivity and events are binary? This complete prospective block contains 216 constructed-world settings across three sample sizes, four schedules, three event rates and six populations. It is a descriptive method calibration, not evidence of a human trait.

The table shows split-day correlations at 2,272 people and mean event rate 0.20. Rows are planted populations; columns are diary schedules. Each entry is a mean over 200 worlds with a 95% interval across eight world blocks.

ONE shares a dial; TWO80/50/0 plant log correlations 0.8/0.5/0. RIVAL30/60 add independent contest readiness. Aggregates also retain bias, spread, availability and ES2 interval classifications. Unavailable estimates are not counted as nulls; correlations are not clipped.

The random-slope moment estimator assumes a linear observation model and is not an exact floor-aware fit. Intervals are pointwise, not adjusted for the grid; the miniature architecture is untested. Sounding Line ES2/MI2 can use the schedule-specific biases and rival landing points; real missingness and event reporting remain untested. ToMpathy receives a method calibration, not a deployed reader.
