# W and Q: separately bounded first resolution healings

The original bootstrap filters fail their frozen particle-resolution checks.
For W's first 128-step exact restriction, resolution error is 0.9404 nats and
exact-reference error is 0.8020, against 0.25 limits; its independent arithmetic
agrees exactly. A Q retained path first fails at 512 steps with resolution error
0.2676, while independent arithmetic differs by less than 1e-13. Other original
jobs reached resource limits or stopped with their failed family. None admits
hidden-reader science.

Use one separately frozen resolution repair per family. Preserve the bootstrap
model, likelihood, reconstruction arithmetic, original fixture seeds and the
same full-length validation ladder. W compares 8,192 and 32,768 particles;
Q compares 2,048 and 8,192. Retain the original setting dictionary for fixture
generation so population changes cannot select different paths. All original
0.25-nat resolution/exact limits and 1e-8 reconstruction limits remain unchanged.

Each family runs its configurations serially in one Gear 2 validation slot,
stopping at the first failed configuration or resource boundary. W has 3,600
CPU-seconds and Q 10,800 CPU-seconds from the existing healing allocation.
W covers both hidden views at all three corners; Q covers both partial views
at all six movement/event combinations. No production is admitted unless every
required full-record gate for its view passes, followed by a separately measured
production cost profile within its original family budget.

This is a bounded numerical-resolution attempt, not a claim that more particles
will be sufficient or affordable. No failed gate is relaxed. Preserve all old
failures. A failed first repair requires a new owner decision before another.
