# D.b: diary reaction and carry

Prospective descriptive calibration, miniature; architecture untested. The V30
EXPOSED, REACTIVE and STICKY parameter centres are used separately. Within a
cell reaction has independent log spread 0.25 and clearing has uniform spread
0.1 around its centre. Exposure also has independent log spread 0.25.
Poisson arrivals interpolate the V30 one-hour event probability; event sizes
are 0.5, 1 and 1.5. Activation decays continuously between event times.

The grid crosses three centres, 300/1,200/2,272 people, 40/90/150/240 minute
prompt gaps, 60/240 prompts and binary shows/continuous intensity with noise
0.2. Each has 40 excluded pilot worlds followed by 200 worlds in eight blocks.
Event slopes and lagged-response slopes are estimated separately within people.
The target is their between-person correlation despite independent true
reaction and clearing, with recovery of each true parameter also reported.
Missing/constant predictors remain unavailable, never zero slopes.

Independent least squares reconstructs the centred-moment estimator on every
retained record. Known slopes and a no-carry control precede admission. This
calibrates descriptive slopes, not a mechanistic inverse fit. It does not cover
ES3's over-240-minute comparison. Route: Sounding Line's ES3 calibration.
