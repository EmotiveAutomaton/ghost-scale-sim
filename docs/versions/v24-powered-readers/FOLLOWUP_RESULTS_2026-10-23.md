Can identification reflect context rather than personal mechanism? In the constructed 45-identity, 17-feature pilot, shared context alone gives 5.76% identification against 2.22% global chance; its matched within-context reference is 6.67%. Reusing the same sample gives 100%. This is a methods warning, not a diagnosis of Sounding Line’s failed controls.

## Reference-calibration interpretation

All 512 gallery cells retain their synthetic arrays. Every uniform relabeling reference is exactly centered at 1/N. Excluding identity assignments changes the expected reference to (1 minus observed accuracy)/(N minus 1): it is below chance when observed matching is above chance. Within-group relabeling instead answers a conditional question. A stable shared context and sample overlap can therefore create impressive identification without the desired personal mechanism. These simulated assignment schemes are not asserted to be the schemes used in Sounding Line. Its 21-channel package, failed controls and unavailable participant-level inputs remain unchanged.

Other-omission averages and high-reliability comparisons retain every source and all four block means. Full 192-cell output is published; no favorable subset is selected for confirmation.
