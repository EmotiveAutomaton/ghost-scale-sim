# R probe order and K attention-only extensions

R enumerates all 720 fixed orders of its six core probes. An independently
implemented mixed-radix path enumerator checks each order. The adaptive greedy
policy chooses maximum expected information with prospective twelve-decimal
auxiliary ties. The order objective is prior-weighted expected probes capped at
six, accompanied by final unresolved and wrong-confidence probabilities; it is
not an uncensored expected time to identification. Exact finite sums have no
Monte Carlo interval or fabricated world count. Replay and independent full-grid
arithmetic replace a sampled forty-world pilot for this exact map.

A probe's value in watched occasions is its prior expected information divided
by expected information in one watched occasion, separately for price/visibility
regimes. This is an information exchange rate, not a guarantee of equal stopping
times. Clock waiting multiplies by the inverse occasion rate; it cannot by itself
change which fixed-cost question has the greatest initial information.

Repeated staged offers separately compare HEAT, refusal and their joint evidence
for 128 offers. Chance HEAT is retained as a known zero-information control.
The conditional performer extension is built/admitted only if the packet's
primary trigger clears; no positive trigger is assumed.

K's watcher sees only attention location: elsewhere, the same gap as last step,
or a different named gap. PLAN with full quieting and no deadline versus no gaps
has an exact Bernoulli-arrival reader: planning itself consumes visible attention.
Strong-plan versus NOPLAN uses an explicitly approximate second-order Markov
projection trained on 128 excluded simulated makers per type. It receives no
arrival, window, completion, stress or private gap-state variables. Independent
transition counts and likelihood recurrences reconstruct every result.
Report observed wrong-confidence rates beside detection times. Training-size
and history-order sensitivities are separate finite reader checks; this reader
is not called an exact hidden-queue likelihood or a ceiling.
