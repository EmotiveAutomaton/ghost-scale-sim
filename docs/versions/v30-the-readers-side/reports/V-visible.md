# V-visible: verified descriptive map

What does a partner gain from seeing the maker's state or knowing the maker's type? The complete 288-setting visible-information map reports entrustment, income, defection, partner payoff and forecast changes under both visibility conditions. This constructed-mechanism map is separate from the still-running hidden-state readers; it does not yet establish a four-way visibility ranking.

Each setting has 200 worlds in eight blocks and 1,024 steps. STATE knows the ledger but learns the type; INSIDE knows the true type. Public refusal cannot update an already known type, a fixed control rather than a discovery. The mimic refuses cheap public offers by construction but behaves as a live sum privately. Forecast-change rows condition on observed refusals; absent events remain unavailable, and price-32 summaries condition on worlds with such an event.
