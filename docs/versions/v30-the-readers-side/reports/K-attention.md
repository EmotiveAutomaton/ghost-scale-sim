# K-attention: descriptive constructed map

Can an attention-only watcher distinguish planning from its controls? This 24-setting map retains separation, unresolved and wrong-confidence estimates. Its strong-plan reader is an order-two Markov approximation trained on excluded makers; it is not an exact hidden-queue likelihood.

For strong planning versus no plan at the low-arrival, high-opening setting with strong-plan truth, the censored median separation was 38 steps (95% whole-block interval 26–38), with wrong-confidence estimate 0.5% (pointwise block interval -0.68% to 1.68%). The interval is an unconstrained normal block interval, not a negative probability. These values are a single setting, not a universal reader performance.

Each sampled cell has 200 worlds in eight blocks, an excluded 40-world pilot, full seed replay and independent reconstruction. Excluded aliases have pilot evidence only. Pointwise intervals are not simultaneous. Generators and summary conventions are shared; miniature — architecture untested; no registered claim.
