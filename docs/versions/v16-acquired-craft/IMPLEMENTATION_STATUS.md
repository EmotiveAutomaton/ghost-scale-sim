The original native, acquisition, reading and behavior scouts passed serialized
public bytes to fixed reader functions within the evaluator process. Public
and private records were separate files, but that was not a separate operating
system process. Do not retroactively describe those scouts as process-isolated.

The new fixed-code reader worker receives only public JSON frames. Following
trusted imports, an audit guard denies file, subprocess and network access.
The known-answer test both reproduces a prediction and denies an attempted read
of a synthetic private answer file. This is a control on trusted scientific
code, not a general sandbox for hostile native programs. Inquiry uses this
worker from its first scout. The separate
[access replay](../../../results/v16/reader-access-replay-1/REPLAY.json) reproduced
all 166,018 retained requests across 4,162 unit records, including two fixtures,
with exact output agreement. Reader replay and full world replay differ.
