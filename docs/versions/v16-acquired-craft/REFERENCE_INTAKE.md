## Native transition options: position before the method read

Observed transition structure may supply useful executable skills without a
personal motif account. The test must compare those options with learned motifs
and primitives under equal exploration and expanded-action budgets. Only observed
edges may support an option. A disconnected or insufficiently explored graph is
a measured coverage limit, not permission to supply hidden world transitions.

The planned native adaptation uses a normalized graph Laplacian. It compares
the first nonconstant eigenspace through its projector, so sign and basis choices
cannot become personal traits. A finite directed observed-graph planner compiles
terminating policies toward selected extrema. This is a bounded generic-skill
challenger, not a reproduction of the paper's full reinforcement-learning setup.

Reference: [A Laplacian Framework for Option Discovery](https://arxiv.org/abs/1703.00956).
No external code, executable package, or dependency was fetched for this component.

Read on 2026-09-09: the paper's normalized-Laplacian definition and option
construction in sections 2.3 and 3. The source uses potential differences as
intrinsic rewards and learns a policy with a termination action. This implementation
uses observed directed shortest paths to projector-selected targets instead.
That difference stays explicit in K04's locked design. No upstream benchmark or
published performance number is claimed reproduced. The read did not change the
local question or confer evidence of a personal-skill mechanism.
