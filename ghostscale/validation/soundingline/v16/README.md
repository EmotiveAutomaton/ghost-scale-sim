# V16 implementation contract

Read docs/versions/v16-acquired-craft/CODING_PACKAGE.md before changing instruments.
A packet freezes its scientific modules, designs, reader access, estimands and seed
namespace before discovery. Changes after outcomes require a new packet lineage.

Readers accept serialized public observations only. Private acquisition histories,
programs and future outcomes stay in separate evaluator files. Exact inference
sums all represented routes to an artifact; impossible evidence remains impossible.
An independent interpreter executes submitted programs. The audit reducer does
not import the experiment's aggregation or scoring implementation.

A supervisor owns status; workers only return immutable units. Module-form entry:
python -m runners.run_v16. Scratch checks cannot write live status. No stage may
reinitialize an accepted campaign or overwrite a packet's completed units.
