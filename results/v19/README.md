For each packet, extract `SOURCE.zip` into a fresh directory. Using the matching
Python/NumPy environment, run the repository's portable replay driver:

```powershell
python -m runners.replay_v19 --packet results/v19/G19-03-local-world-1 --source extracted-source --retained-root retained-v18-4 --output replay-output
```

Use the project interpreter in place of `python` on the native workstation.
Run only with ownership of the scientific worker. Retained-data packets require
the two L2d predecessors extracted beneath `retained-v18-4`; the exact input plan,
source, completion and raw-block hashes are pinned in their plans. Local-world
replay does not read this retained-data argument. Do not write into a prior output
directory. The driver checks source/environment identity and regenerates all
declared output hashes, including the private evaluator output where applicable.

The result is a finite constructed-method record. Replaying deterministic fixtures
is not retraining a model, confirming G-P1, or testing transfer to human intention.
