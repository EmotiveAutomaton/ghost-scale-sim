```powershell
python -m runners.replay_v19 --packet results/v19/G19-03-local-world-1 --source extracted-source --retained-root retained-v18-4 --output replay-output
```

Use the project interpreter in place of `python` on the native workstation.

replay does not read this retained-data argument. Do not write into a prior output
directory. The driver checks source/environment identity and regenerates all
declared output hashes, including the private evaluator output where applicable.
