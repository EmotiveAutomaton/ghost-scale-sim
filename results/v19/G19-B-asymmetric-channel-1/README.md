# Asymmetric cue errors: verified result

We tested whether storage choices remain robust when cue mistakes favor a particular wrong label. Guarding against directional errors lowers worst expected regret in 143 of 420 problems relative to the symmetric-error policy, and improves on fixed storage in four. Independent reconstruction and both full replays verify this constructed-method result; forecast accuracy and process correspondence remain unestablished.

All policy decisions, raw population joins, independent regroup, source/input/environment bindings and both complete replays are retained. Reader inputs: none. [Report](../../../docs/versions/v19-local-maker/ASYMMETRIC_CHANNEL_REPORT.md).
