## Original metadata and its correction

The frozen exporter reused early-pilot wording in [reader.zip](reader.zip) and
[EXPORT.json](EXPORT.json). Their outcome-blind selection wording is incorrect for
this final cohort. The final rule selects the lowest case hash within each observed
outcome type and each native observer family in the completed expansion cohort.
These are outcome-selected illustrations, not an unbiased evaluation population.

`reader-final.zip` is the delivery artifact. Only README.md and its member-manifest
entry changed. [PORTABILITY.json](PORTABILITY.json) and
[PORTABILITY_RECHECK.json](PORTABILITY_RECHECK.json) retain the two successful
original-archive executions; TRANSFER_FINAL.json records the delivered archive's
third execution. The old export's false portability flag predates those executions.
No original receipt is rewritten to conceal its history.

All five requested illustrative types exist in evaluator material. Wrong-recipient,
wasted-computation and surprising-edit types are absent as blind reader types.
The plausible-history-wrong tag is a proxy for multiple compatible histories plus
a wrong future forecast; it does not score a uniquely identified historical path.
Read [TRANSFER.md](../../../docs/versions/v17-adaptive-appreciation/TRANSFER.md)
before using the challenge. The trusted consumer's file guard is not a general
hostile-code sandbox.

## Reproduction and retained limits

For bounded scientific replay, extract replay-bundle.zip and follow its README.
Use the exact admitted native Stitch executable/runtime identified in PLAN.json
and Python 3.13. The command refuses changed sources and external dependencies.
It regenerates selected units and the controller; no scientific sampling window
is restarted. The selected database cannot regenerate full-campaign aggregates.

With access to the complete retained run root, the standard-library
`runners.verify_v17_closeout` command accepts `--run-root`, a fresh `--out`,
`--source-archive` and `--failure-archive`. It reaggregates every unit and rereads a
new complete raw archive. The source and four known-answer tests are committed;
full verification takes hours. The published receipts record the actual full pass,
not merely a configured command.

Pooled assembly retains its failed constructor and curtailed denominator.
Robustness subtype mixtures are restricted by deterministic scheduling; revision
has only 96 distinct constructions. Normal descriptive intervals do not establish
equivalence or repair those limitations. V15's C11/M01 gate failures remain visible:
the last full CI on pre-closeout HEAD 46dad18 failed only that test. Four closeout
known-answer tests passed again during filing. This is qualified scientific closure,
not a claim that the repository's historical test suite is entirely green.
