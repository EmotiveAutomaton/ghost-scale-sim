# Sounding Line profile-feature dependency validation

Can the exact trained predictor distinguish an informative description from a
matched donor or an uninformative description without using future outcomes?
This is a bounded method study requested October 15. It does not promote a
human result, recover values, or replace the larger empirical twin program.

Before any scientific outcomes, freeze 20 independent constructed worlds, eight
writers, four chronological decisions each, four actions and three conditions:
planted profile signal, independent random descriptions and a constant description.
Each condition has the exact baseline, own and matched-donor arms. A donor is a
fixed random derangement of writers with the same number of opportunities and
profile cutoff. Every world redraws signal probability uniformly from .70 to .95,
the type/action mapping, words and their hash collisions, zero to two nuisance
words, task context, writer ordering and resolution delays. There is no tuning
on these outcomes and no optional continuation to obtain a desired verdict.

Execute the unchanged ASTs of Sounding Line's `profile_vector`, `choice_features`,
`predict_all` and nine-dimensional task `features` functions, archived with their
full source-file hashes. Use committed ToMpathy 82789fdb50d9, its unchanged fitting,
32 normalized SHA-256 word buckets and four action indicators: 164 columns in
every arm. The actual handler fits only strictly earlier resolved records. The
later personal-penalty calibration is not exercised by four decisions per writer.
Earlier profile descriptions are supplied constructed observations, not generated
by a language model. Profile-generation fidelity is outside this study.

The evaluation unit is one entire independent world, never a single correlated
choice. Compute mean half-Brier loss (half the squared probability error) and
paired own-profile improvement over baseline and donor, including cold starts.
Use descriptive two-sided Student t 95% intervals across the 20 world means.
For planted signal both lower bounds must exceed .005. For each null both upper
bounds must be at most .005. These are finite-generator diagnostic criteria,
not calibrated family discoveries or a claim about arbitrary descriptions.
Random descriptions can act as writer fingerprints; the null is intentionally
allowed to expose that problem. Constant extra features can also change the
engine's effective prior; a failed null must remain a failure.

For every world, mutate all labels resolving at or after the twelfth opening and
refit the full roster; the first twelve forecasts must agree within 1e-7. Permute
option rows and labels consistently, refit, and undo the permutation: forecasts
must agree within 1e-7. Constant own/donor forecasts must agree within 1e-12.
Check every training-ID set against strict chronology, every probability vector,
and all output coverage. Keep reader inputs, historically revealed labels and
evaluator truth in separate retained files. Truth sidecars never enter fitting.

A disjoint one-world cost pilot runs first; it is explicitly a software fixture
and cannot become the research witness. Admission requires the conservative
projection (20 worlds × five full comparisons × two passes × 1.5 plus 120 seconds)
to fit within 7,200 CPU seconds. The pilot has a 900-second total cap. Both runs
use V23 accounting, immutable sources, one below-normal CPU worker and one thread;
no protected allocation, environment synchronization or human-data access.

Cost-only amendment before scientific exposure: the original six-decision pilot
already exceeded the full-study projection at its incomplete 99-CPU-second
checkpoint. Preserve that capsule and its eventual outcome. Four decisions per
writer and a disjoint second cost-pilot seed reduce work; the 20 independent
worlds, three conditions, controls and criteria stay fixed. Neither pilot's
scientific scores inform this decision. The narrower calibration limitation above
must accompany any witness. Original protocol is retained with the pilot records.

The complete scientific run receives a fresh-process full replay. A separate
checker reconstructs scores and control differences from retained raw files.
Only complete, independently checked evidence satisfying every frozen criterion
can receive `scope: ghost`, `status: PASS`. Failures and incomplete scope remain
explicit; a transport fixture is never relabelled as an admission witness.
Sounding Line separately owns its native adapter and exposed-holdout approval.
