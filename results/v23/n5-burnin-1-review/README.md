# N5 first burn-in review

The projection study has one complete, independently checked discovery batch:
128 settings, 16 worlds per setting and 64 cases per world (131,072 cases).
All retained probabilities and proper scores were rebuilt from raw evaluator
labels; complete original/replay hashes, source capsules, frozen fits, raw case
identities and the calibrated machine card were checked.

The decision is **BURN_IN**, not a nomination or confirmation. The finite queue
may admit the required second batch when a scientific slot and budget are
available. The approximate hierarchical reader is not an exact ceiling.

REVIEW.json binds the evidence; DIAGNOSTICS.json retains every setting's summary,
CURVE.json and TRAJECTORY.json retain the calibrated selection state, and
RAW_HASH_INDEX.json binds all replayed scientific files. No human inference.
