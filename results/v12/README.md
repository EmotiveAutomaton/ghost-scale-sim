# V12 results: what is filed where

Read the curator packet first:
[`docs/versions/v12-the-other-model/RESULTS.md`](../../docs/versions/v12-the-other-model/RESULTS.md).
The generated ledger of every card is beside it in `RESULTS_PACKET.md`. Nothing in this directory
needs to be opened to read the results; it is the machine record the packet was generated from.

| file | what it is |
|---|---|
| `QUEUE_MANIFEST.json` | the program: every card with its question, construction, estimand, floors, wave, module, state, amendments and closure reason. States are the spec's allowed states; `DONE` is forbidden |
| `prereg_v12_lock.json` | the pre-specification lock, written before any card ran: hashes of the card set, the per-card criteria and the lock module. `python -m ghostscale.prereg_v12` reports whether it still matches |
| `COVERAGE.json` | mandatory cards resolved, by state and by trunk |
| `RUNTIME.json` | wall time and state per card for the discovery lane (the latest run of each card) |
| `CONFIRMATION.json` | the confirmation pass: which cards were promoted, whether their criteria held on the untouched lineage, and wall time |

Verdicts live under `results/validation/soundingline/v12/`:

| location | what it holds |
|---|---|
| `<CARD>.json` | the discovery-lane verdict of record, one per card (74). Each carries its hypothesis, claim ceiling, gates, results, effective n, environment, runtime and the source hash of the module that produced it |
| `attempt1/<CARD>.attempt1.json` | the first discovery-lane verdicts of the nineteen cards re-run under deviation D-V12-1 (the Q trunk, B04, and the X matrix). Kept, never re-read by the tooling; the gate walker still checks them |
| `confirmation/<CARD>.json` | the confirmation-lane verdicts of the twenty-two promoted cards, run on worlds 100–111 |
| `*.produced` | completion markers the runner checks after each card; regenerated by every run and not committed |

Lineages: discovery worlds 0–11; confirmation worlds 100–111; transfer worlds 200–211 (S08 and
X12 during discovery, so the confirmation lineage stayed untouched until its pass). Seeds are
CRC32 of named strings; every world is reproducible from its id.

To re-run: `runners/run_v12.py --lane discovery` skips resolved cards and resumes;
`runners/run_v12_confirmation.py --auto` re-runs the promoted set; `runners/report_v12.py`
regenerates the packet; `runners/validate_v12_program.py` checks the manifest, lock and verdicts.
